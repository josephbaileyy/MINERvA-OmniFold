## 1. What was varied (review F6)

- **Both shifts.** The simulated reconstructed recoil is scaled by s = 0.96 (`RecoilResponse:0`) and s = 1.04
  (`RecoilResponse:1`), in two places:
  - reco E_avail (`NewEavail()`, a linear sum of tracker and ECAL blob energies × 1.17, so the scale is exact);
  - the calibrated reco energy transfer `<tree>_recoil_E`, which enters reco q3 and reco W.
- **The simplification.** The two are scaled **separately, by the same factor**. A real response difference would
  act on the calorimetric response before calibration, and per particle species. MAT's per-particle response map is
  not used; it is commented out in the source. This single coherent scale is acceptable only under the exploratory
  label.
- **What is not varied.** Data, truth, weights and selection are untouched.
- **The data moves, the null does not.** Each shifted observed statistic is tested against the **frozen** null
  ensemble. For strongly non-central nulls (λ = 318–6,344) the size of that approximation is unmeasured. "Robust"
  means "not removed by this data-side variation".

## 2. Verification of the implementation, and a limit of that check (review F2)

- **What the comparer can see.** The W2a comparer checks q0 through the identity q3² + W² = (q0 + M)². That
  identity **cannot see the Q² term**: a defect that moved Q² and W together would pass it.
- **How the gap was closed.** The reviewer predicted q3 from the muon kinematics with E_ν = E_μ + s·q0. It matched
  within 2.5e-10 GeV on every passing smoke row, including the rows clipped to W = 0.
- **Full-1A check.** The full-1A shifted outputs match the production 1A CV omnifile in every unshifted branch. Reco
  E_avail = s × production, with relative error ≤ 2.3e-16.
- **The lateral dump.** `s5p_input_dumps.py lateral` requires the observed events to equal the CV npz's. It accepted
  all three merged W2b omnifiles (rc 0), which closes the last W2a "not verified" item about the dump.
