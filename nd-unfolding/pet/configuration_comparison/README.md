# PET configuration comparison against Gregor's implementation

A code-traced comparison of our production full-event PET estimator against
`gregorkrz/minerva-ml`, and the design for selecting between them.

**Read `MATCHED_COMPARISON_PROPOSAL-20260918.md` first.** The deck is an **interim
inventory**: it records what differs and why it might matter. It does **not** select a
configuration, and neither configuration has been evaluated head-to-head on our
unfolding task. The proposal is the bounded campaign that would settle it; **nothing in
it is launched.**

**PET is diagnostic method development.** Nothing here is a publication adoption, an
uncertainty product, a central-value change, or a Gate-6 action. No proposed component
described here is deployed.

## Reproducing

```sh
REPO=$(git rev-parse --show-toplevel)
GREGOR=/Users/josephbailey/local-research/gregor-audit/minerva-ml   # pinned fc9a099d

python3 measure_model_capacity.py --repo "$REPO" --gregor-checkout "$GREGOR" \
  --gregor-commit fc9a099d3c9c060f03cef293c294f9de4eb019cd \
  --output receipts/model-capacity.json
python3 measure_typed_object_budget.py \
  --source-receipt ../direct_token_comparison/local_validation/20260918-source/source-multiplicity.json \
  --output receipts/typed-object-budget.json
python3 make_figures.py --budget receipts/typed-object-budget.json \
  --cost ../direct_token_comparison/local_validation/20260918-a3-cost/cost-half.json \
  --outdir slides/figures
python3 -m unittest test_typed_object_budget
( cd slides && pdflatex -interaction=nonstopmode recommended_pet_configuration.tex )
```

`measure_model_capacity.py` sets `TF_USE_LEGACY_KERAS=1` itself: the vendored PET is
Keras-2 code and will not build under Keras 3.

## What this does not establish

**That either configuration unfolds better** --- no head-to-head has been run, and his
configuration has never been evaluated on the powered-closure endpoint. Also not
established: that our configuration is better than Gregor's; that typed objects preserve the
information our cluster cloud carries (**unmeasured, and the prerequisite for the three
largest borrowings**); that aggregation improves closure (**no closure measurement of
aggregation exists**); or that the token cap binds as often in the selected,
POT-weighted population. See `CLAIM_EVIDENCE_INDEX-20260918.md` §M.
