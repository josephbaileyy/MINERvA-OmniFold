% Retraction marking. Repo convention is to STRIKE THROUGH rather than erase, so a
% reader who remembers a superseded number finds it struck rather than vanished
% (docs/orchestration/INDEX-retracted-and-superseded-values.md).

% Works in BOTH text and math mode: \mbox gives \sout an LR box to strike, and
% \ensuremath restores math for the (usual) numeric argument. Needed because most
% call sites are numbers already inside $...$, where \sout alone fails.
\newcommand{\dead}[1]{\mbox{\textcolor{gray}{\sout{\ensuremath{#1}}}}}
% Reviewer-comment macros. SHARED rather than note-local since 2026-08-19: they were
% defined in main_note.tex only, yet the paper is written by distilling commented note
% paragraphs, so the first distillation carrying a \gk{} would fail the paper build with
% Undefined control sequence. Latent build-breaker, not a defect in current output --
% paper_body.tex and primer_body.tex use them 0 times today. Definitions are byte-identical
% to the main_note.tex originals; only their location changed.
\newcommand{\bpn}[1]{\textcolor{blue}{\textbf{[BPN: #1]}}}
\newcommand{\jrb}[1]{\textcolor{violet}{\textbf{[JRB: #1]}}}
\newcommand{\gk}[1]{\textcolor{orange}{\textbf{[GK: #1]}}}
