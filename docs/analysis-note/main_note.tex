This note reports a cross-section measurement with unbinned OmniFold unfolding of MINERvA's public medium-energy neutrino data, in up to five observables at once: the muon's transverse and longitudinal momenta, the available hadronic energy, the three-momentum transfer and the hadronic invariant mass. In the muon momenta, the unfolding reproduces the published cross-section integral within about one percent, with a correlated shape difference whose source has not been identified. Adding the hadronic observables gives central values in three, four and five dimensions and a cross section on sixteen five-observable cells, given only as an illustration. A binned iterative Bayesian unfolding of the same inputs differs from the method on these cells. Fake-data studies find residual bias exceeding criteria fixed before the tests were graded. Rounding-level changes of the inputs move the five-observable estimator's results by more than the criterion of a data-stability test set before it ran. Data from different run periods are mutually inconsistent before unfolding, for a reason not identified. No reported interval has validated coverage. The procedure's two-observable covariance under-covers jointly at both held-out tunes, and a five-dimensional coverage test failed its futility criterion.
