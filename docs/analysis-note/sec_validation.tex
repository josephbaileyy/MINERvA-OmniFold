\section{Validation}
\label{sec:validation}

\paragraph{Closure.}
Three existing closure families were exercised (1A lgbm 5-iter; thresholds in parentheses):
\begin{itemize}
  \item \textbf{Truth-reweight} (multiply truth and reco weights by the same
        factor): gaussian-$\pT$ residual \SI{0.046}{\percent}, tilt-$\pPar$
        \SI{0.013}{\percent} (thr \SI{1.5}{\percent}) --- injected truth recovered.
  \item \textbf{Hidden-variable} (bias on $\Delta\pT=\pT^{\mathrm{reco}}-\pT^{\mathrm{truth}}$,
        a resolution variable not in the feature set): leakage linear in amplitude,
        $A=0.05/0.10/0.30\to0.57/1.14/3.43\,\%$ (thr \SI{3.0}{\percent});
        the first two amplitudes pass and the deliberately large $A=0.30$ arm exceeds
        the threshold.
  \item \textbf{Alt-model} (train on CV, pseudo-data from an alternative universe):
        MaCCQE \SI{0.068}{\percent}, Flux \SI{0.376}{\percent} (thr \SI{2.0}{\percent}).
\end{itemize}

\paragraph{Bottom-line test.}
Following the unbinned-unfolding guide~\cite{unbinnedguide}, the unfolded result must
recover the data's deviation from the prior with a residual far smaller than the feature
itself (the unfolding cannot manufacture discriminating power). Using the closure runs,
in the bins carrying the injected feature the unfolded result tracks the injected truth to
$\approx10\times$ better than the feature size: 2D (gaussian-bump truth reweight) residual
\SI{1.69}{\percent} vs injected \SI{17.2}{\percent} (ratio $0.098$); 3D (+\SI{30}{\percent}
$\Eavail$ bump, $\Eavail$ projection) \SI{1.84}{\percent} vs \SI{18.1}{\percent} (ratio
$0.102$). Both pass.
(The naive data-vs-prior form---reco vs truth $\chi^2$---instead has truth$>$reco, as
expected for a high-resolution measurement where detector smearing lowers the reco baseline
and a stat-only diagonal omits the unfolding covariance; the proper full-covariance
goodness-of-fit is the $\chi^2$-vs-paper of \S\ref{sec:results-tension} and the generator
comparisons.)

These closure tests validate the estimator but are not used to assign a
non-closure uncertainty. Such an uncertainty would require a predeclared suite
of injection shapes and amplitudes rather than calibration to a single
Gaussian bump.

They also do not test the distinct failure mode in which pseudo-data are
generated with a detector response that disagrees with the response supplied
to the unfold. Appendix~\ref{app:response-mismatch} defines a complementary
record-only $\Eavail$ response-mismatch closure and a more complete
leading-nucleon follow-up. No result from that test is claimed here.

\paragraph{Unbinned diagnostic (C2ST).}
As a binning-free check that the unfold removes the data\,$\leftrightarrow$\,MC mismatch, we use
a classifier two-sample test (C2ST): a classifier is trained to separate the data from the
(reweighted) simulation in the full unbinned feature space, and its held-out AUC/accuracy is
compared to the chance value $0.5$. The discriminator AUC drops from $\approx0.535$ before
unfolding to $\approx0.501$ after, indicating that the reweighting removes the reconstructed
data--MC mismatch. We report this strictly as a \emph{descriptive} diagnostic and do \emph{not}
quote a calibrated $p$-value: the C2ST as run trains and evaluates on the same sample without
cross-fitting, and a valid null would require re-running the full (cross-fitted) OmniFold
pipeline per pseudoexperiment. Calibrated unbinned goodness-of-fit remains an
open problem~\cite{unbinnedguide}.

\paragraph{Toy residuals and coverage status.}
The existing 200 2D closure toys fluctuate both the unfolded result and the
stored \texttt{hTruthXSec2D} through the MC bootstrap. The stored truth varies
in all 205 reported bins, so its all-toy mean is not an independent fixed truth
for a split-sample coverage claim. We therefore quote no 2D coverage number
from this ensemble. Its same-ensemble figures
(\SI{\pullFrac}{\percent}, $\langle|r|\rangle=\pullMeanAbs$ vs
$\sqrt{2/\pi}=\pullGauss$, and \SI{97.6}{\percent} of bins above
\SI{65}{\percent}) are retained only as standardized-pull/Gaussianity
diagnostics. A coverage test requires an independently stored unfluctuated
truth reference (or a redesigned ensemble) and remains open.

\paragraph{Stability.}
5-iter total $\sigma$ within \SI{0.026}{\percent} of 10-iter (per-bin shape RMS
\SI{1.54}{\percent}); HistGBT and exact-GBT agree on total $\sigma$ to
\SI{0.04}{\percent}. Efficiency (Fig.~\ref{fig:eff}) reproduces the published
Fig.~5.

\paragraph{Classifier choice (GBDT vs.\ NN).}
Published OmniFold analyses use neural-network
classifiers~\cite{Andreassen:2019cjw,unbinnedguide}; we use gradient-boosted decision
trees, whose output must still be a calibrated posterior for $w=p/(1-p)$ to be valid.
On the step-1 reco classifier (data vs.\ MC reco) the reliability curve is near-diagonal
(Brier \(\approx0.25\) at AUC \(\approx0.537\): data and reco MC are nearly
indistinguishable, so the reweight is a modest correction). A full scalar
Keras-MLP OmniFold cross-check on the same weighted 3D inputs and five-iteration
loop gives total ratio $1.0078$ versus the GBDT reference and median projection
differences of \SIrange{0.7}{1.4}{\percent} (Fig.~\ref{fig:calibration}).
The agreement in the populated bulk establishes that the scalar result is not
specific to the production classifier family. A stronger family cross-check, on a
low-level recoil point-cloud representation rather than the engineered scalars, is
reported with the rest of that track in \S\ref{sec:pet-shape}.
