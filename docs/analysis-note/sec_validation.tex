\section{Validation of the two-dimensional measurement}
\label{sec:validation}

In a simulated experiment, \emph{truth} is the known target distribution, the \emph{prior} is the starting simulated truth distribution, and the \emph{response} describes reconstruction and selection conditional on truth. A closure test compares the unfolded estimate with its known target under a specified deformation. Bias is the mean estimate minus that target over repeated experiments; a single closure residual also contains sampling fluctuations. Coverage is the fraction of repeated intervals containing the specified truth, and tests the estimator and interval procedure together. Table~\ref{tab:validation-questions} separates these questions before the results. Repeating a numerical calculation checks neither the coverage and width of the intervals nor the adequacy of the physical model.

\paragraph{Injected-feature recovery.} The 2D truth-reweighting closure with a Gaussian bump passes the recovery test of the unbinned-unfolding guide~\cite{Canelli:2025guide}. In the feature bins the residual from the injected truth is \SI{1.69}{\percent} for an injected \SI{17.2}{\percent} feature (ratio $0.098$), about ten times smaller. The test requires the residual left after recovering a deviation from the prior to be far smaller than the deviation itself; unfolding cannot create discriminating power (3D: \S\ref{sec:3d-closure}).

A naive data-versus-prior $\chi^2$ with a statistical-only diagonal is larger at truth level than at reco level. This is expected at high resolution: detector smearing lowers the reco-level value, and the diagonal omits the unfolding covariance. The full-covariance comparisons are the $\chi^2$ against the published result (\S\ref{sec:results-tension}) and the generator comparisons.

These closure tests validate the estimator; no non-closure uncertainty is assigned from them. Assigning one would require a predeclared suite of injection shapes and amplitudes, not calibration to a single Gaussian bump.

None of these tests uses pseudo-data whose detector response differs from the unfolding response. Appendix~\ref{app:response-mismatch} defines such a test, a closure that rescales only the reconstructed $\Eavail$ of the pseudo-data, together with a more complete leading-nucleon follow-up. \subsection{Closure tests across dimensions: what each test changes}
\label{sec:closure-map}

Only the MINERvA simulation supplies a detector response, the conditional distribution of reconstructed events given truth. Other generators (GiBUU, NuWro, GENIE variants) supply truth only. Every closure test here therefore keeps the simulated MINERvA response and changes the truth distribution, by reweighting the simulated events, or changes the analysis chain around it. Reweighting to another generator's shape is a valid known-truth test of the unfolding; it is not a test of the detector model. A closure test is only as informative as what it changes: an ordinary closure, whose pseudo-data are the simulation itself, is an identity check that a constant estimator would pass. \paragraph{Why injected bumps close while generator-shaped tests do not.} The closing tests and the failing tests measure different things, so they do not contradict each other.
\begin{itemize}
  \item \emph{Deformation.} The closing injections are single smooth bumps in one variable the classifiers see directly. A generator ratio changes correlated structure across $\Eavail$, $W$ and $q_3$, including directions the reconstructed observables constrain weakly (\S\ref{sec:coverage-5d}, response-information diagnostic).
  \item \emph{Metric.} The 3D, 4D and 5D closures are judged on one-dimensional marginals, where per-cell errors average out; the 3D test's per-bin spread is already \SI{3.2}{\percent}, and the 5D test's is \SI{3.7}{\percent}. The generator-shaped failures are measured in joint $(\Eavail,W)$ cells.
  \item \emph{Iterations.} At five iterations the estimator retains part of the prior wherever the data pull weakly. Thirty iterations reduce the $\Eavail$ residual by \SI{26}{\percent} while the $q_3$ residual grows (\S\ref{sec:val-departure}).
  \item \emph{The five-dimensional $W$ test passes only in the marginal, and narrowly.} A $W$ bump at the $\Delta$ peak is recovered to a ratio of 0.180 against a threshold of 0.20. The same unfold leaves joint $(\Eavail,W)$ cells in the peak column up to \SI{9.4}{\percent} low and moves part of the bump into the neighbouring $W$ bins. A single smooth bump in a marginal is therefore weaker evidence than the generator-shaped tests, which remain the main five-dimensional recovery evidence of \S\ref{sec:5d}.
\end{itemize}

\subsection{Fixed-truth coverage of the 2D statistical band}
\label{sec:coverage}
This test asks whether the 2D statistical band quoted when it ran covers a \emph{fixed} truth at its nominal rate. That band is an earlier one, not the quoted statistical block. The design, criteria and positive control of the test were specified before any toy was generated (Ref.~\cite{NoteRecords2026}, \recentry{coverage-fixed-truth}).
% J3/J4 provisional (DECISION-20261018, packet W3: D2). The quoted statistical block became S1 (sec:uq-boot), which this
% test did not score (NR).
% plain-language pass (DECISION-20261018-joseph-plain-language-pass)

Each toy draws pseudo-data event by event as Poisson counts with means equal to the simulated reconstructed weights. It resamples the simulation with the production Poisson(1) bootstrap and unfolds with the statistical band's estimator (LightGBM, five iterations, fixed training seed): the learner of the quoted central value, at a different seed (\S\ref{sec:method-config}). The reference $T$ is the unfluctuated simulated truth, identical in every toy. The no-fluctuation configuration reproduces both the production closure output and $T$ exactly.

In reported bin $b$ of toy $t$, $z_{tb}=(U_{tb}-T_b)/(r_b T_b)$, where $r_b$ is the production band's relative spread. Coverage $C_k$ is the fraction of all (toy, bin) pairs with $|z|\le k$, with intervals from resampling whole toys. The band counts as nominal if its ratio to the true scatter lies in $[0.9,1.1]$, which gives the windows $C_1\in[\covTwoDWinOneLo,\covTwoDWinOneHi]$ and $C_2\in[\covTwoDWinTwoLo,\covTwoDWinTwoHi]$. A failure at the interim analysis of 100 toys, with 99.5\% intervals, stops the study.

\textbf{The band fails: it undercovers in its tails.} At the interim analysis ($N_{\text{toy}}=\covTwoDNtoy$, 205 bins):
\begin{itemize}[nosep]
  \item $C_1=\covTwoDCOne$ $[\covTwoDCOneLo,\covTwoDCOneHi]$ is nominal (Gaussian 0.683).
  \item $C_2=\covTwoDCTwo$ $[\covTwoDCTwoLo,\covTwoDCTwoHi]$ lies entirely below its window (Gaussian 0.954).
  \item The pull RMS is $\covTwoDPullRMS$, and the mean pull is consistent with zero.
\end{itemize}
By the criteria above this is a failure by undercoverage, and the study stopped at the interim analysis. An independent recomputation with its own code reproduces the pooled coverages, their intervals, the controls and the secondary analysis below.

The positive control rescales the band on the same toys. At $\times0.7$ and $\times1.3$, $C_2$ moves to $\covTwoDCTwoLowCtl$ and $\covTwoDCTwoHighCtl$, and the test flags both directions.

The failure is one of width, not bias. The per-bin pattern below is descriptive and post hoc.
\begin{itemize}[nosep]
  \item \textbf{Uneven in both directions.} The band is too wide in $\covTwoDNwide$ bins (pull RMS below 0.9) and too narrow in $\covTwoDNnarrow$ (above 1.1). The pooled $C_1$ is nominal partly through this cancellation; the median bin's pull RMS is $\covTwoDBinRMSmed$.
  \item \textbf{Where it is too narrow.} $\covTwoDNlowCTwo$ bins have a per-bin $C_2$ below 0.85. Of these, 21 form a block at $\pPar\ge\SI{15}{GeV/c}$ and $\pT<\SI{0.55}{GeV/c}$. Six more lie in the highest-$\pT$ row (\SIrange{2.5}{4.5}{GeV/c}) at $\pPar$ \SIrange{6}{20}{GeV/c}. The $\covTwoDNedge$ bins with pull RMS above~2 carry \SI{\covTwoDDeficitShare}{\percent} of the $C_2$ deficit.
\end{itemize}

The band's replicas divide by a bootstrapped completeness, whereas the central value's completeness is exactly~1. A secondary analysis, added by amendment after the pilot, applies the same division to the toys. Scored against the same band, it overcovers: $C_1=\covTwoDRepCOne$, with its interval above the window. The attribution rule was fixed before the full run, but its clause for the undercoverage outcome was written after the pilot pulls had been seen. \subsection{Other validation diagnostics}
\label{sec:val-other}

\paragraph{Unbinned diagnostic (C2ST).} In the classifier two-sample test (C2ST), a classifier is trained to separate the data from the (reweighted) simulation in the full unbinned feature space, and its held-out AUC or accuracy is compared with the chance value $0.5$. The AUC drops from $\approx0.535$ before unfolding to $\approx0.501$ after, indicating removal of the reconstructed data\,$\leftrightarrow$\,MC mismatch. This binning-free check is descriptive, and no calibrated $p$-value is quoted. As run, the C2ST trains and evaluates on the same sample without cross-fitting; a valid null would require re-running the full cross-fitted OmniFold pipeline per pseudoexperiment. Calibrated unbinned goodness-of-fit remains open~\cite{Canelli:2025guide}.

\paragraph{Same-ensemble pull diagnostic (not a coverage test).} An earlier ensemble of $N_{\text{toy}}=200$ 2D closure unfolds (Ref.~\cite{NoteRecords2026}, \recentry{coverage-toys}) uses weighted MC reco pseudo-data and stores the truth marginals in truth histograms. Each toy has its own bootstrap seed $k$ and per-event Poisson(1) draws, as in production, with seeds chosen not to collide with the production replicas. Toy seeds are independent; bins within a toy are correlated. The MC bootstrap multiplies the truth weight, so it fluctuates both the unfolded result and the stored truth. The stored truth varies in all 205 reported bins, and its all-toy mean $\bar X^{\text{truth}}$ is therefore not an independent fixed truth for a split-sample coverage claim; it only centers a same-ensemble diagnostic.

In reported bin $i$ with $\bar X^{\text{truth}}_{i}>0$, define the across-toy standard deviation $\sigma_{i}$ (ddof $=1$) and standardized residual $r^{(t)}_{i}=(U^{(t)}_{i}-\bar X^{\text{truth}}_{i})/\sigma_{i}$. Compare the per-bin fraction $c_{i}$ of toys with $|r^{(t)}_{i}|\le1$ to the unit-normal $\Phi(1)-\Phi(-1)=\mathrm{erf}(1/\sqrt 2)\approx0.6827$ and the mean absolute pull $\langle|r|\rangle$ to $\sqrt{2/\pi}$. The fraction with $|r|\le1$ is \SI{\pullFrac}{\percent} (Gaussian reference $68.27\%$; $\Delta = +0.44\%$; median $68.50\%$), and $\langle|r|\rangle=\pullMeanAbs$ against $\sqrt{2/\pi}=\pullGauss$ (within $0.5\%$). The signed residual mean is $+0.006 \pm 0.082\,\sigma$ (no bias). The within-bin fraction is above \SI{65}{\percent} in \SI{97.6}{\percent} of bins (only $5$ of $205$ fall below). These show that the standardized toy residuals are approximately normal.

Because $\sigma_i$ is estimated from the same toys that are scored, these figures are standardized-pull and Gaussianity diagnostics only: they do not certify the bootstrap band, and no coverage number is quoted from this ensemble. The 2D coverage statement is the fixed-truth test of \S\ref{sec:coverage}.
