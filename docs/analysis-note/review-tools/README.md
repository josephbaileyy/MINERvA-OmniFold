`meaning_read.sh <tag> <base> <head> [manifest]`: three independent model reads (Grok, Gemini, Claude Opus 4.6) of a note diff, each grading every hunk as OK, DROPPED, WEAKENED, ADDED or POINTER against the pre-image and the move manifests. sha256 `8cd2015a3e5ed02c9d5ada78e7b95618aa00d47d5f7e6876fa30175d91c7e778`.
`readability_read.sh <pdf> <tag>`: Gemini readability reads of a built note in four page ranges (a score out of 10 against the calibration "published papers read at 6-7", the hardest passages and unglossed labels) plus a skim pass that counts takeaway-first captions. sha256 `ceadaab93de3b864656a33a75d983f4a5b4d04de9864452a39644a2a663cc802`.
`quality_grade.sh <pdf> <tag> <n_figures> <n_tables>`: Gemini checklist graders per section, figure group and table group, plus a navigation test, each writing issues as JSON lines with counts by rubric key; the deterministic counterpart is `../quality_checks.py`. sha256 `d3224b98a94fda02c9e2ac245552f049b7b54104a3786ec4e9468e8175270226`.
The model reads are aids to review, not proofs: a PASS or a score is one model's reading, and every finding is checked against the text before anything changes.
The scripts are byte-for-byte copies of the reviewers' working tools (2026-11-18); their reports are written outside the repository (`~/codex-reports/note-measurement/`) and are not committed.
