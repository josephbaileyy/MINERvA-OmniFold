\paragraph{Considerations for using these results.}\label{sec:usage}\label{sec:limitations-use}
These rules apply to any use of the results.
Use the two-dimensional cross section with its full covariance $Q_R$, and add $C_{\mathrm{model}}$ to include the generator-shape dependence (\S\ref{sec:uq-2d-scope}).
The comparison with the published result shares the data and systematic uncertainties, and its $\chi^{2}$ values are therefore descriptive (\S\ref{sec:results-compare}).
The 2D covariance gives no calibrated significance for comparisons with generator predictions (\S\ref{sec:limitations-2d}).
Use the sixteen cells as an illustration, not for fitting or for constraining models (\S\ref{sec:fived16}).
Quote no generator significance from the 3D and 4D central values, which have no covariance, or from $C_Z$ (\S\ref{sec:3d}, \S\ref{sec:eavailw-adopted}).
Do not read the generator tests as physical exclusions of generators (\S\ref{sec:joint5d}).
New projections require their own applicability checks; nominal weights alone cannot certify arbitrary downstream inference (App.~\ref{sec:unbinned-inference}).
