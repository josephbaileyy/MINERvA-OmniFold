\section{What the validation shows}
\label{sec:part-q3}

What do the validation tests show about the method's bias, stability and uncertainty? In two observables, closure tests of injected changes pass except at one deliberately large change to a hidden variable, with passes that depend on the type and size of the change, while the covariance under-covers jointly at both held-out generator tunes. For the sixteen reported five-observable cells, simulated-data tests at two truths, judged with the reported covariance, find residual bias beyond limits fixed before grading, and at those truths the result keeps part of its prior; rounding-level changes of the inputs also shift the estimates beyond a stability criterion set before the test, and the cells differ from a binned unfolding of the same inputs. No reported interval has validated coverage, and the sixteen cells on data are given only as an illustration.
