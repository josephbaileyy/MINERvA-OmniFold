\section{Summary and outlook}
\label{sec:summary}

\paragraph{Summary.}
The executive summary (p.~\pageref{sec:execsummary}) lists each result with its
scope; this section states the conclusions they support. The main results are the validation
findings, which hold for this implementation and for the configurations,
observables and deformations tested; the generator tests are an application that
illustrates calibrated inference with a biased estimator.

\paragraph{Reusing the unbinned result.}
The public ATLAS charged-particle phase-space release
\cite{ATLAS:2026fpsdata} exemplifies unbinned distribution. The emerging
\texttt{omnifold\_publication} proposal \cite{Bajpai:2026publication} emphasizes
weight-family metadata, normalization, row alignment, and checksums.
A MINERvA release should likewise specify event
identity, estimator and uncertainty-family definitions, units, support,
normalization, and a reproducible projection example.
App.~\ref{app:release} specifies this release for our analysis, including which of its objects
already have fixed identities and which are still to be produced.
A local release candidate, with checksums and a verifier that recomputes and
checks its results, exists, but \textbf{no release has been tagged or
deposited}; rebuilding this note's PDFs assembles documents and reproduces no scientific result
(App.~\ref{app:release}). New projections
require their own applicability checks; nominal weights alone cannot certify arbitrary
downstream inference (App.~\ref{sec:unbinned-inference}). The release design and its
public example have no bearing on the choice of covariance (\S\ref{sec:eavailw-adopted}).
