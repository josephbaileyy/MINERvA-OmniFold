\paragraph{Principal limitations.} The principal limitations, each stated in the body with the result it qualifies, are these. The quoted two-dimensional statistical block has had no coverage test (\S\ref{sec:uq-boot}, \S\ref{sec:coverage}). The generator comparisons of \S\S\ref{sec:3d}--\ref{sec:eavailw} are descriptive comparisons of central values that identify no nuclear or interaction mechanism. No 3D or 4D covariance is quoted (\S\ref{sec:3d}). The five-dimensional estimator recovers only part of truth changes of about the size of generator differences. No quoted uncertainty includes this residual bias, which is interpreted as regularization bias (\S\ref{sec:val-departure}). Above two dimensions the results are central values without intervals of validated coverage. No five-dimensional measurement with total uncertainties was constructed (\S\ref{sec:gbdt-model-dependence}). Bias-corrected statistical intervals of a deterministic five-dimensional estimator variant miscover at the tested truths (\S\ref{sec:coverage-5d}). The one five-dimensional covariance used in this note does not meet its specification's acceptance criteria. Two companion covariances, built at different estimator seeds, show a seed sensitivity above the limit set before production, so no covariance-based significance is quoted (\S\ref{sec:eavailw-adopted}). The calibration of the generator tests is valid for the simulated null to the extent that the pseudo-experiment chain reproduces the analysis applied to the data (\S\ref{sec:joint5d-frozen}). Their nuisance model has no calorimetric recoil-response band (\S\ref{sec:joint5d-response}).

\paragraph{Outlook.} The scalar extended-fiducial study (\S\ref{sec:fps}) yields a preliminary central value $\sigma_{\mathrm{ext}}=\SI{\fpsSigma}{cm^2/nucleon}$, against \SI{\sigTwoDPurity}{cm^2/nucleon} for its control unfold in the restricted phase space. New acceptance-supported cells contribute about \SI{6}{\percent} of the rate; separately labeled prior-dominated extrapolation contributes about \SI{28}{\percent}. Further refinements are a fifth external generator, NEUT, and a finer 44-cell comparison with the Ascencio \emph{et al.} measurement (the maximal-common-grid comparison is in \S\ref{sec:4d}). A flux--muon-energy-scale posterior derived from MAT-MINERvA, independent of the published analysis, would let the correlation $\rho$ between the leading flux mode and the muon-energy-scale band (\S\ref{sec:systematics}) be derived entirely within this analysis.

\paragraph{Reusing the unbinned result.} The public ATLAS charged-particle phase-space release \cite{ATLAS:2026fpsdata} exemplifies unbinned distribution. The emerging \texttt{omnifold\_publication} proposal \cite{Bajpai:2026publication} emphasizes weight-family metadata, normalization, row alignment, and checksums. A MINERvA release should likewise specify event identity, estimator and uncertainty-family definitions, units, support, normalization, and a reproducible projection example. App.~\ref{app:release} specifies this release for our analysis, including which of its objects already have fixed identities and which are still to be produced. A local release candidate, with checksums and a verifier that recomputes and checks its results, exists, but \textbf{no release has been tagged or deposited}; rebuilding this note's PDFs assembles documents and reproduces no scientific result (App.~\ref{app:release}). New projections require their own applicability checks; nominal weights alone cannot certify arbitrary downstream inference (App.~\ref{sec:unbinned-inference}). The release design and its public example have no bearing on the choice of covariance (\S\ref{sec:eavailw-adopted}).
