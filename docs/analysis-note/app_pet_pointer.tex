\section{Future work: point-cloud representations}
\label{sec:pet}

We are developing unfolding with point-cloud transformer (PET) representations
of the full event, which could use low-level detector and particle information
that the scalar observables of this note summarize. That work is in progress and
is documented separately (\texttt{docs/analysis-note/pet\_note.tex}, \repolink).
No central value, uncertainty or comparison from it is used or claimed in this
note.
