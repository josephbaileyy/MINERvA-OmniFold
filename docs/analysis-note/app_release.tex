\section{Result package and reproduction limits}
\label{app:release}

This appendix describes RC7, the existing local replay package, and specifies the broader event-level and covariance release, with the identities that are fixed and what each part does and does not reproduce. Rebuilding this note's PDFs assembles documents; it does not reproduce scientific results.

\paragraph{Release status.} RC7, a local release candidate with a README, checksums and a replay verifier~\cite{ReleaseCandidate2026}, has not been deposited or released under a publication tag. Run on the packaged files in an empty directory, RC7's own verifier reproduces the recorded observed statistics of the joint tests; the $p$ value and count of every test and variant; the decision of every test; the robustness results and power figures; and every number quoted from a figure that it checks. The package, about \SI{16}{MB} of sufficient inputs, reproduces the joint-test $p$ values, decisions, robustness labels and power results; the same results with the recovered pseudo-experiments added to the calibration and the variant shifts recomputed on all draws (\S\ref{sec:joint5d-lost}); the matched coarse-projection comparison (\S\ref{sec:joint5d-projections}); and the fine-grid $L_2$ ratios of condition~(i) (\S\ref{sec:joint5d-conditions}). From packaged arrays it also regenerates figures of the earlier article version for which it was assembled: the $(\Eavail,W)$ excess map (Fig.~\ref{fig:eavailWexcess} of this note), the null distributions of the joint tests (Fig.~\ref{fig:joint5d-nulls}), and one-dimensional generator projections, which neither this note nor the current article prints. RC7's two-dimensional curve is the exact-split one, which was the two-dimensional central value when the package was assembled. The current article's two-dimensional validation figure and its numbers were instead drawn separately, from the committed values and covariance of the refined LightGBM result, with RC7's plotting code extended to draw this analysis's band.

\paragraph{Contents and use.} The package holds:
\begin{itemize}[nosep,leftmargin=2em]
  \item the sufficient inputs of the joint tests, for the evaluation behind the decisions and for the evaluation with the recovered pseudo-experiments added;
  \item the arrays behind the figures of the earlier article version;
  \item the noise-free differences behind the $L_2$ ratios;
  \item an inventory of the analyzed AnaTuples;
  \item the replay and figure code, and the expected outputs.
\end{itemize}
The package's verifier (\texttt{publication/release/verify\_rc.py} in the repository) runs from the top directory of the unpacked package, in a fresh Python environment with the package's pinned requirements (numpy, scipy and matplotlib). It performs every replay and figure check and prints \texttt{VERIFY: PASS} if all agree. In the two replays of the joint tests, floating-point values must agree to a relative $10^{-12}$, and integers and decisions must agree exactly. Each number that the earlier article version quoted from its Figs.~1--3 must agree with its printed value to within half a unit of its last printed digit, and the $L_2$ ratios must reproduce their printed range. For the three figures themselves, the check is that their files are produced. The package also carries the 20 rounding jitters of the data, from which the stability of the observed $p$ values (\S\ref{sec:joint5d-conditions}) can be recomputed; no packaged script recomputes it.

\subsection{Scope of reproduction and required inputs}
\label{app:release-scope}

The public ancillary files of Ref.~\cite{MINERvA:2021owq} supply the published inputs for the comparisons to its central values and covariance, the standardized differences, the tension anatomy, and the MINERvA~Tune~v1 model comparison, but not for this analysis's unfolded 2D uncertainty construction.

RC7 supports replay of the higher-dimensional inference from sufficient inputs. It does not support extraction from the archived pseudo-experiment products (about \SI{2.3}{GB}), event-level unfolding, the quoted closure and bias measurements, or the measurements behind the covariance's status (\S\ref{sec:eavailw-adopted}). Nor does it reproduce the 2D uncertainty and coverage figures, the low-recoil comparisons, the recoil-response sensitivity, or the proxy convergence rate of joint-test condition~(i). The multiplier scan of the joint tests is recomputable from RC7's sufficient inputs with the scan code of Ref.~\cite{JointTestKappa2026}, but it is not part of RC7's own verification. An earlier version of the package, RC1, was replayed from an empty directory by a separate AI agent session (Opus~5.5) that had no access to the repository and used only the package and its README; its verifier passed. Event processing requires the earlier production of MINERvA \href{https://doi.org/10.15484/3022562}{open-data AnaTuples}, event-loop outputs, and the generator samples used here.

\subsection{Release schema}
\label{app:release-schema}

The broader result package must contain every item below; RC7 does not contain all of them. A $\checkmark$ marks identities or values already fixed (bin edges: \S\ref{app:release-edges}; checksums: Ref.~\cite{NoteRecords2026}, identities already fixed); the rest are packaging. A fixed identity specifies which object is meant, not whether the object is scientifically qualified.

\begin{enumerate}[itemsep=2pt]
  \item \textbf{Reporting bin edges and units, per axis} $\checkmark$: $\pT$ and $\pPar$ in \si{GeV/c}, $\Eavail$, $q_{3}$ and $W$ in \si{GeV}, with each wide terminal catch bin identified.
  \item \textbf{The flattened-cell ordering} $\checkmark$: the dense $14\times16\times7\times7\times6$ grid in C order, with the reported subset supplied as an explicit index array, never inferred from a positivity cut.
  \item \textbf{Central values}: the five-axis array and every projection quoted, each with its own checksum, on the density scale in \si{cm^2/nucleon} divided by the product of its kept axes' units.
  \item \textbf{Covariances} $\checkmark$: the five-axis covariance of the configuration-(a) central value and its $(\Eavail,W)$ projection, with the algebra of Eqs.~\eqref{eq:zassembly}--\eqref{eq:zinflation}, the declared centering variant, and the band partition.
  \item \textbf{Masks} $\checkmark$: the support mask, the pinned mask (bins where the inflation denominator vanished and $g$ was declared $1$), and the unreported-cell mask.
  \item \textbf{Projection matrices} $\checkmark$: $M$ itself, with its content checksum, its shape, and the explicit statement that its entries are the dropped axes' bin-width products, which is needed to specify the destination units.
  \item \textbf{Generator predictions}: the four truth-level $(\Eavail,W)$ predictions (GENIE-CV, GENIE$+$Valencia~2p2h, NuWro, GiBUU) and the MINERvA~Tune~v1 ancillary model, as arrays on the release binning rather than figure curves, each with generator version, configuration, target and flux. GENIE and NuWro require the flux-repaired predictions of 2026-09-27 (per-event reweight to the analysis PPFX flux plus the 50--\SI{100}{GeV} supplements); GiBUU requires its reweight to the same flux convention (\S\ref{sec:3d-models}).
        % KNOWN_ISSUES.md rows 82--83
  \item \textbf{Provenance}: for each object, the producing code revision, the job, and the checksum of the bytes read back from the closed file. Of these, only the following are fixed: the assembling revision and job of $C_{Z}$, the job of $C_{EW}$, and the read-back checksum of the row index. No producing revision or job is recorded for the other objects, and the assembled package carries none.
  \item \textbf{One minimal worked example}: \S\ref{app:release-example}.
  \item \textbf{Limiting measurements}: the four measurements of \S\ref{sec:eavailw-adopted} that limit what the five-axis covariance of the configuration-(a) central value supports, stored with it in the released package, not only in this note.
\end{enumerate}

\subsection{Bin edges}
\label{app:release-edges}

\noindent The bin edges are the one thing a reader cannot recover from a checksum:
\begin{itemize}[nosep,leftmargin=2em]
  \item $\pT$, \si{GeV/c}: $0$, $0.07$, $0.15$, $0.25$, $0.33$, $0.40$, $0.47$, $0.55$, $0.70$, $0.85$, $1.00$, $1.25$, $1.50$, $2.50$, $4.50$ (14 bins).
  \item $\pPar$, \si{GeV/c}: $1.5$, $2$, $2.5$, $3$, $3.5$, $4$, $4.5$, $5$, $6$, $7$, $8$, $9$, $10$, $15$, $20$, $40$, $60$ (16 bins).
  \item $\Eavail$, \si{GeV}: $0$, $0.1$, $0.2$, $0.4$, $0.8$, $1.5$, $3.0$, $100$ (7 bins).
  \item $q_{3}$, \si{GeV}: $0$, $0.2$, $0.4$, $0.6$, $0.8$, $1.2$, $2.0$, $100$ (7 bins).
  \item $W$, \si{GeV}: $0$, $1.1$, $1.4$, $1.8$, $2.2$, $3.0$, $100$ (6 bins).

The last bin on $\Eavail$, $q_{3}$ and $W$ is a catch bin to \SI{100}{GeV}, and the $\pT\times\pPar$ grid carries the 19 unreported high-$\pT$, low-$\pPar$ acceptance cells of \S\ref{sec:method-binning}.

\subsection{One minimal projection example}
\label{app:release-example}

The released package is to support the following computation, which checks the package's ordering, mask and weights from end to end.

\begin{enumerate}[itemsep=2pt]
  \item The five-axis central values $\mathbf{x}$ have \num{65856} entries, and the reported-cell index array has \latBins\ entries.
  \item $M$ has shape $\zprojCells\times\latBins$, and $C_{Z}$ has shape $\latBins\times\latBins$. The five-axis covariance of the configuration-(a) central value is the file \texttt{z-cv.npz}, with \texttt{sha256} \zcvDigest\ldots\ and $\sqrt{\Tr C}=\SI{5.6742e-38}{}$, so a loaded $C_{Z}$ can be checked against both.
  \item The projection $\mathbf{y}=M\mathbf{x}_{\text{reported}}$, reshaped to $7\times6$ \textbf{in C order}, must reproduce the $(\Eavail,W)$ central-value map of Fig.~\ref{fig:eavailWexcess}. The F-order control establishes the ordering: C order agrees with the figure to a relative $1.7\times10^{-16}$; F order disagrees at relative $1.0$.
  \item The projected covariance $C_{EW}=M\,C_{Z}\,M^{\top}$ is checked by $\sqrt{\Tr C_{EW}}=\SI{4.4552e-39}{}$ and exact symmetry ($\max|C-C^{\top}|=0$). Its numerical rank depends on the cutoff, because the spectrum decays smoothly with no plateau: the retained count is 26 at $10^{-6}$, 36 at the projector's hardcoded $10^{-12}$, 41 at \texttt{numpy.linalg.matrix\_rank}'s default, and 42 with no cutoff. The rank is therefore not an integrity check: with NumPy's default cutoff, an intact matrix fails a test for 36. The check is instead that $|\lambda_{\min}|/\lambda_{\max}$ is of order $10^{-15}$, the edge of double precision; the matrix is ill-conditioned, without a definite rank. Do not check the sign of $\lambda_{\min}$, which sits at the noise floor and carries no information; a second host reproduces $\lambda_{\min}$ to only five significant digits.
  \item The per-cell relative uncertainty is $\sqrt{(C_{EW})_{rr}}/y_{r}$. Because $M$ carries the dropped axes' widths, $\mathbf{y}$ and $C_{EW}$ are on the \emph{density} scale. Converting cell $r$ to an integrated cross section requires multiplying by that cell's own $\Delta\Eavail\,\Delta W$, and the catch bins make that factor large.
  \item $C_{EW}$ should \emph{not} be inverted without a declared regularization: its spectrum runs continuously down to the double-precision noise floor, so an inverse is set by the regularizer rather than by the data. The estimator-seed sensitivity, which exceeds its limit (the first measurement of \S\ref{sec:eavailw-adopted}), is why no significance is computed from it.
\end{enumerate}

\paragraph{Undeclared acceptance field.} The record of the projection carries \texttt{acceptance\_question: UNDECLARED}: when the projection was built, it had not been decided whether an acceptance correction is needed at the destination binning. The package must carry this field with its value until that is decided, so that no default in the data format makes that scientific choice.
