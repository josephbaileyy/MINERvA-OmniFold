\section*{Guide to the appendices}
\addcontentsline{toc}{section}{Guide to the appendices}

The appendices fall into three groups.
\begin{itemize}[itemsep=1pt, topsep=2pt]
  \item \textbf{Methods and context for the body.} Statistical methods and the 2D comparison
        (App.~\ref{app:statmethods}) and those for the multidimensional results and inference
        (App.~\ref{app:statmethods-nd}); unbinned background subtraction
        (App.~\ref{app:negweight}); the detector-response-mismatch closure, a protocol implemented
        but not yet run (App.~\ref{app:response-mismatch}); and the survey of MINERvA measurement
        dimensionality (App.~\ref{app:landscape}).
  \item \textbf{Future work.} Point-cloud (PET) representations, documented separately (App.~\ref{sec:pet}).
  \item \textbf{Release and code.} The result package and what it reproduces (App.~\ref{app:release}), and the
        code layout (App.~\ref{app:codebase}). These are reference material; a physics reading can skip them.
\end{itemize}
The note's records --- the provenance of the repository records it cites, the fixed-identity table and audit
record of the five-axis covariance, the test-suite discipline, and the audit trail of superseded values and
withdrawn arguments --- are kept in a separate internal records document, Ref.~\cite{NoteRecords2026}, which is not part of
this note; the note cites its entries by tag or by heading.
