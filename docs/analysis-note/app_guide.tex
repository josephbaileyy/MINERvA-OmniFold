\section*{Guide to the appendices}
\addcontentsline{toc}{section}{Guide to the appendices}

The appendices fall into three groups. The first gives methods and context for the body: statistical methods and the 2D comparison (App.~\ref{app:statmethods}) and those for the multidimensional results and inference (App.~\ref{app:statmethods-nd}); unbinned background subtraction (App.~\ref{app:negweight}); the detector-response-mismatch closure, a protocol implemented but not yet run (App.~\ref{app:response-mismatch}); and the survey of MINERvA measurement dimensionality (App.~\ref{app:landscape}). The second, on future work, covers point-cloud (PET) representations (App.~\ref{sec:pet}). The third describes the result package and what it reproduces (App.~\ref{app:release}) and the code layout (App.~\ref{app:codebase}); it is reference material and is not needed to follow the physics results. The provenance of the records the note cites, the fixed identities and audit record of the five-axis covariance of the configuration-(a) central value, the test-suite discipline, and superseded values and withdrawn results are kept in the analysis repository's records document, Ref.~\cite{NoteRecords2026}; each citation names the entry's number or heading.
