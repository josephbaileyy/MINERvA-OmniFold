## 3. The five things that will bite a fresh session, none of which are in the code

1. **Never `git add`** — **except that the remedy has no path for a NEW file, and you will hit
   that on your first new artifact.** `git commit -F <file> -- <paths>` errors
   `pathspec ... did not match any file(s) known to git` for anything untracked, so for a new
   file the published rule offers *nothing* and the only fallback is the `git add` it forbids.
   That is BEN-134, and this handoff repeated the remedy without its exception until Session C
   hit it on both inventory artifacts. **Use a private index instead:**
   `GIT_INDEX_FILE=$(mktemp -u)` → `git read-tree HEAD` → `git add -- <paths>` →
   `git write-tree` → `git commit-tree` → `git update-ref refs/heads/<branch> $new $old`
   (the old value makes it a compare-and-swap, so a concurrent lane cannot be clobbered).
   Then **read the committed contents**, not the path list — I verified a private index by its
   paths, exactly three as intended, and it still absorbed 1325 lines of another lane's work.
   Four lanes share one checkout and one index. Use `git commit -F <file> -- <paths>`
   — and know that this protects only files you **do not name**; for a named file it takes the working
   tree, staged or not. `git diff --cached --stat` is a TOCTOU read, not a guard, and so is checking the
   file is clean first. **Read the committed contents afterwards with `git show --stat` and file a scope
   correction when it fires** — that is a detector, not a preventer, and it is the only thing that
   worked. Five absorption events across four lanes in one night, every one by a session applying the
   then-current published remedy. `BEN-113`, `BEN-115`.
2. **One git identity across all lanes** until last night, so `git log -S` answers *which commit*, never
   *which agent*. It produced a **false confession** — a lane confessed to two absorptions that were its
   peer's own commits. Attribution comes from the self-identifying line in the commit body, present in
   ~14% of the history. Adopt decision 11 and write the lane line. `BEN-160`.
3. **A false confession is more durable than a false accusation.** An accusation gets checked; a
   confession reads as already-verified because it is costly to the confessor. Source your claims about
   your own conduct as hard as your claims about others'.
4. **A remedy of the form "write it down and read it" must be assumed to fail.** The fired-but-unread
   check is now a committed script, `docs/orchestration/waker_fired_but_unread.sh` — **run it, do not
   retype the query.** Re-deriving it produced `events/` instead of `logs/` twice, the second time from a
   session that had been handed the literal command with its own failure mode named in the imperative.
   `BEN-097`.
5. **The remedy for shared mutable state was itself shared mutable state**, three times: a private-index
   patch (shared index), the pathspec commit (shared working tree), per-lane `git config` (one config
   file). Check what your fix writes before you trust it.
