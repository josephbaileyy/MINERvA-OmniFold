# Fact ledger: register round r15 (origin/main afb7e1fa → branch `stageF/register-r15-20261023`)

**Governing record:** `docs/orchestration/DECISION-20261023-joseph-5d-a-and-register-round.md`.

**Scope.** Every printed sentence of `paper_body.tex` and `main_paper.tex` at afb7e1fa that the round changed has at
least one row here. The sentence ids (`P#` for `paper_body.tex`, `M#` for `main_paper.tex`) are those printed by
`check_ledger.py --list` against afb7e1fa. Each id numbers the comment-stripped, whitespace-collapsed sentences of that
file, so a float that runs into a sentence carries that sentence's id. A sentence that still prints verbatim needs no
row: the checker finds it.

**Dispositions.**
- `KEEP`: the fact still prints in the paper. Its wording may change, its meaning does not.
- `KEEP (KEEP list Ex)`: a qualifier the register study's KEEP list holds in place (REPORT.md §5, example Ex), or one
  that a Joseph decision fixes. The reason follows.
- `MOVE→L`: the fact now prints once, in the new limitations list (Sec. VIII A, `sec:limitations`).
- `MOVE→S`: the fact now prints once, in the Sec. I scope paragraph.
- `MOVE→note`: the fact leaves the paper and already prints in the note. The `N:` probe shows where. The round added
  nothing to the note.
- `COLLAPSED→row`: a repeat. The fact still prints at the row named.
- `REPOINT`: only a pointer changed. It is now a plain clause at the paragraph end, or it was merged with the next
  pointer of the same paragraph. The pointer's target section is unchanged.

**Probes.** `P::text` must occur in the printed `paper_body.tex` of the worktree, `MP::` in `main_paper.tex`, and
`N:file::text` in that note file. Several probes are joined by ` && `. `check_ledger.py` runs every probe and the
coverage and protected-text checks. A probe proves only that the text is present. Each row's meaning was checked by
reading.
