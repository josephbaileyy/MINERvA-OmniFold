Each receives a reco-bin \emph{purity} weight. The step-1 classifier retains the full unbinned kinematics. Binning enters only through this multiplicative correction, an ${\sim}\SI{3}{\percent}$ effect overall, largest where backgrounds concentrate (\S\ref{sec:selection}).
