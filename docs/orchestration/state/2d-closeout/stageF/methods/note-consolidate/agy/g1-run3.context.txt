ROW R09a (passage sec_validation:61): fact: Every closure test keeps the simulated MINERvA detector response
  home sec_validation.tex: "Every closure test here therefore keeps the simulated MINERvA response"
    in its paragraph: Only the MINERvA simulation supplies a detector response, the conditional distribution of reconstructed events given truth. Other generators (GiBUU, NuWro, GENIE variants) supply truth only. Every closure test here therefore keeps the simulated MINERvA response and changes the truth distribution, by reweighting the simulated events, or changes the analysis chain around it. Reweighting to another generator's shape is a valid known-truth test of the unfolding; it is not a test of the detector model. A closure test is only as informative as what it changes: an ordinary closure, whose pseudo-data are the simulation itself, is an identity check that a constant estimator would pass.
