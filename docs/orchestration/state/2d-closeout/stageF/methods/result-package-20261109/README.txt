RESULT PACKAGE: the methods paper's tables and figures as data (generated by build_package.py; do not edit)

STATUS: INCOMPLETE. Pending: ENS1, FD-PRR, LL5D, V-HALF, 2D-ARRAYS (package/pending/).
Nothing here is deposited, tagged or uploaded. Whether and where it is released is Joseph's decision.

WHAT THIS IS
  Every file is written by build_package.py from committed records only. The build contacts no cluster and
  recomputes no result. Each record is pinned by sha256, and every written value is checked against the
  paper's own values: its \fvval key in docs/analysis-note/values_fived16.tex (which must equal a fresh run of
  make_values_fived16.py), its macro in docs/analysis-note/values.tex, or, for a value with no key, the paper's
  printed text at bc8673186ba945460dfee4e4ee78ec1012ec9174. Any disagreement stops the build.
  Files are named by the paper's LaTeX \label at bc867318 (':' written '-'), not by table number,
  because the restructure renumbers the tables. The label map moves with the restructure (PR #977).

REPRODUCE (from the repository root, at the commit that holds this README)
  python3 docs/orchestration/state/2d-closeout/stageF/methods/result-package-20261109/build_package.py --check
  It exits 0 only if a rebuild equals every committed file here byte for byte; --self-test plants a wrong
  value in each check family and confirms that the build refuses it. Python 3, standard library only; git is
  needed to read the paper at bc867318.
