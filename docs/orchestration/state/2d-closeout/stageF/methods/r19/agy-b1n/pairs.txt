Q6.
BEFORE: Two properties must be distinguished. The coverage of unfolded intervals is the rate at which they contain the true cross section. The calibration of a test is the rate at which it rejects a true hypothesis. Calibration can be obtained without validated intervals by simulating the whole analysis chain at the hypothesis, so that the estimator’s bias enters the simulated null distribution. A calibration obtained in this way is valid to the extent that the simulated chain reproduces the analysis of the data. Unfolded results can be compared with any prediction at truth level without simulating each generator through the detector, which is what makes the two-dimensional result reusable and the higher-dimensional central values usable for qualitative comparison, and the sixteen-cell result usable for the comparison of Sec. V A. For hypothesis tests the advantage is smaller. A test at reconstruction level would avoid the regularization bias, but it would still need the same response model. Each external prediction would have to be folded through the analysis simulation’s response, which is the hybrid construction of Sec. VI A, with the same composition below the fine grid. The tests of this section instead calibrate the unfolded statistic in simulation, so that the bias enters the null distribution rather than the decision. We have not compared their power with that of a reconstruction-level test.
