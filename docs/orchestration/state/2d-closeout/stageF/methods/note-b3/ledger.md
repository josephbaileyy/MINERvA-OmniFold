**Dispositions.**
- `KEEP`: the fact prints in the same subsection (wording may change, meaning does not).
- `KEEP (guardrail: ...)`: a qualifier kept because without it a printed sentence would be false as read.
- `KEEP (verbatim: ...)`: kept word for word because a build check probes the exact text.
- `SCOPED`: kept, with its scope now built into the sentence (item 1 of the task).
- `NEW (source)`: newly printed, copied from the named source.
- `REMOVED (pure record; records print it)`: a pointer or history clause with no fact a reader needs; the records
  location given prints it (probe `R:`).
- `REMOVED (duplicate of row)`: the fact still prints at the named row.

**Probes.** `N:<file>::text` must occur in the comment-stripped, whitespace-collapsed source of that note file after the
rewrite; `R:<file>::text` the same in a records file; `P::text` in `paper_body.tex`; `X:<file>::text` must NOT occur
(removed text). Several probes are joined by ` && `. `check_ledger.py` runs them and, separately, the token audit
below. A probe shows that the text is there; the meaning of each row was checked by reading.
