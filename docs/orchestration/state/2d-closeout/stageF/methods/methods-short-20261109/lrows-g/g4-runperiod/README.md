## What it shows

Each panel shows one period group against **one reference, P_A = 1A–1F, at both levels**. These are the per-period
unfolding's own groups (`period-unfold-20261014/scripts/periods.py:9-12`). The quantities are binned in p_∥ on the
16-bin analysis grid and summed over p_T.

- **Reconstructed:** R_X = (D_X − B_X)/S_X, with every playlist's simulated signal and background scaled to its own
  data POT before summing. This is the playlist-spread proxy (`playlist-spread-20261014/scripts/ref_shape.py`), from
  proxy_hists.py's per-playlist yields (`work_proxy.npz`) and POTs (`proxy_hists_meta.json`). It is plotted as
  R_X/R_A, with the data statistical uncertainty. It covers every reconstructed event in the 14 × 16 grid, without
  the unfolding's 205-cell mask.
- **Unfolded:** the per-period unfolding's double ratio, data over each period's own simulated truth, of the
  integrated p_∥ yields. The source is analysis.json [`comparisons/dr_X/PA/marginal_ratio_minus_1/pz`], for RE-2's
  refined background, which is the reported two-dimensional configuration.
  - Its bars are the bootstrap noise σ of the p_∥ marginal [`…/noise/sigma_pz_marginal_pct`], from ten paired draws.
  - That σ belongs to the cell-projected marginal, and the figure uses it as this ratio's band. The caption should
    call it the bootstrap noise, not an uncertainty of the ratio itself.
- **The step printed in each panel** is q(8–15 GeV/c)/q(1.5–8 GeV/c) − 1 of the integrated yields
  (`analyze_periods.py:152-168`).
