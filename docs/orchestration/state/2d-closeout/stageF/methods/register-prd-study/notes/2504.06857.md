- **Where limitations live.**

  - **Abstract.** It contains no limitation. It states the design ("mock data study") only.
- **Model dependence, regularization or unfolding bias.**
  - **Regularization as a known property.** It is introduced in one sentence: Q[2504.06857]: "Iterating a finite number of times is a form of regularization, and there are a number of metrics that can be used to decide when to stop." (main.tex:75, Unbinned Unfolding with OmniFold)
  - **Iteration choice.** The cheat in the stopping rule is disclosed in the same paragraph as the choice, as one plain sentence: Q[2504.06857]: "However, this is not a feasible approach for a real data analysis, since it relies on knowing the truth-level target distribution."   - **Bias measure.** The bias is measured by a named metric (the triangular discriminator, "serving as an estimate of solely the bias"), not a caveat: Q[2504.06857]: "The results from evaluating the triangular discriminator between each unfolded result and the true data distribution are shown in Tab. N, serving as an estimate of solely the bias." (main.tex:273, Results)
  - **Not measured.** The paper never computes a model-dependence uncertainty, because it is a single-fake-data study. (inference) It does not say this explicitly.
- **Failed or partial validations, negative results.** Several are stated plainly as results, with an attributed cause and with no hedge stacking:

(main.tex:327, Conclusions)
  - Q[2504.06857]: "The observation that MultiFold performs better than OmniFold across all metrics also serves as another indication that the classifier training is imperfect." (main.tex:305, Results)

- **Patterns worth copying.**
  1. Define once how a term will be used ("we will refer to the fake data simply as 'data'", l.119), so that later sentences need no qualifier.
  2. Disclose an unrealistic design choice in one sentence next to the choice (l.250), then never repeat it.
  3. Report a negative comparison as a finding with a stated cause ("did not show strict improvement … seems to stem from imperfect neural network training", l.327), followed by the positive conclusion, unhedged (l.331).
