## Part B — Findings

1. **BLOCKER (b) — C-COUPLE can accept a false coupling.** Location: §2.2 and C-COUPLE. In one cell, canonical row weights `(1, 1)` and original-signal row weights `(0.5, 1.5)` give exactly equal CV totals. With matched factors `(0, 1)`, the canonical replica total is `1`, while r3’s formula gives `1.5`. Different event identities can produce the same failure even with equal weight distributions. Checking the same original population in both centrals cannot resolve it. Phase 17 adds truth-only misses, but the Python loaders have different gates, including the signal loader’s extra reco-weight check. `r3:136–152,249`, `re2_driver_at_M.py:66–79,644–660,774–810,1785–1802,2431–2461`. **Fix:** bind evidence of a one-to-one event mapping and equal or cellwise proportional weights after the actual loader cuts. Assert the Phase-17 flag and canonical denominator. If the mapping cannot be established, bind an explicit denominator resampling design before licensing a result under the claimed coupling.

2. **BLOCKER (c) — C-COUPLE can reject exactly matched events.** Location: the `1e-9` gate. The separate `TH2D.Fill` loops can accumulate identical nonnegative weights in different orders. A valid one-cell fixture with one weight `1` and twelve million weights of `2⁻⁵³` differs by about `1.33e-9` between large-first and small-first binary64 accumulation. The two populations in that fixture are exactly coupled. The actual pinned run might pass. The post-Phase-18 C++ signal gate reduces the concern about the missing Python vertex cut, and the Tier-1 off score reports a maximum completeness of `1.0000000000000158`. That maximum supplies neither a lower bound nor a cell-by-cell check on M’s grid. The receipt supplies no per-cell summation bound. `r3:140–144,249`, `re2_driver_at_M.py:66–79,1230–1244,1898–1904,2456–2461`, `REF-C2C1-DECLARATION.md:119–125`, `oofvc-r3-score.json.txt:270–277`. **Fix:** use a common stable summation on the verified pairs, or derive a tolerance from the actual per-cell counts and accumulation methods. Record both zero masks and the worst residual on M’s grid. Diagnose genuine population differences separately from rounding.

3. **BLOCKER (a) — The lost-support rule is defensible, but its stated trigger can miscount cells.** Location: §2.2’s final cell-table row, C-SUPPORT and §8. `T*orig = 0` means every original row with **positive truth weight** has factor zero. The loader permits zero truth weights, so a zero-weight row can draw a positive factor. A preflight that tests every original factor for zero can print the wrong count. Under verified coupling, `D* = 0` and setting `c* = 0` implements the CV `Divide` and extraction convention on resampled inputs, including when moved rows survive. Historical **off** production also returns zero there for finite ratios. It fills `hUnfold2D` with `ratio × resampled truth weight` and divides the resulting zero by frozen CV completeness when positive. An R replica using frozen completeness could instead have a nonzero unfolded count from surviving moved rows. `r3:153–168,413–420`, `re2_driver_at_M.py:774–781,1230–1244,1321–1335,2303–2305,2406–2410,2431–2448`, `oofvc_driver.diff:131–137`. **Fix:** define and count loss using the weighted sum and truth mask, distinguish historical off production from R with frozen completeness, and record which lost cells retain moved weight. The rule leaves the central \(\delta_R\) unchanged. Its replica zeros can change the bootstrap mean, covariance, retained modes and both bars. For example, a cell with difference \(d\) on supported draws and zero on a fraction \(p\) of draws has mean \((1-p)d\) and variance \(p(1-p)d^2\). Retaining all seeds avoids conditioning on support. The zero rule alone establishes neither invalidity nor calibration of the empirical null. `ref_c2c1_read.py:128–140`.

4. **BLOCKER (c) — §7 can stop a campaign that fits the launch budget.** Location: §7’s per-replica estimate. At the scoped `0.0489` node-h per replica with four concurrent lanes, one lane takes about `704 s`. The literal r3 pilot rule charges that full lane time to each of the 199 remaining replicas, projecting about `39.34` node-h including the `0.42` node-h pilot. The same timings fit in 50 four-slot node waves, for about `10.20` node-h including the pilot. `r3:388–396`, `PTMC-SCOPING.md:26,34–49`. **Fix:** project the actual allocation in node-hours using four lanes, the slowest lane per wave, tail occupancy and overhead. Keep the prospective `12.5` node-h cap and apply the `11.5` node-h launch rule to the packed estimate.

5. **BLOCKER (b) — A replica can use the same moved entry twice and pass C-DRAW-R.** Location: C-MOVE, C-PAIR and C-DRAW-R. C-MOVE checks skip/injection disjointness in the central comparison. In a replica, a defect can retain a moved row in the background fill and still append it to signal. C-DRAW-R reconstructs injection from those post-skip fill rows, so it can approve the erroneous injection and the correct append. Both methods then receive the same defective inputs. The full-stream lengths and sums remain correct. The measured-side checks also leave a gap between the observed refinement return and the measured weights used by both methods. `r3:235–246,253–269`, `oofvc_driver.diff:20–27,126–145`, `re2_driver_at_M.py:343–346,387–392,2193–2209,2244–2251,2279–2286`. **Fix:** in every replica, verify skip and injection IDs against the pinned rows and an independent pre-skip loader reference. Verify that appended IDs map to the actual coordinates, masks and scaled weights received by OmniFold, and match the refinement return to its measured input.

6. **BLOCKER (b) — Incorrect extraction normalization can pass on a replica.** Location: C-FIX, C-FILL-IBU and C-COMP. If one R replica passes twice the correct data POT to extraction, OmniFold and both IBU extraction routes share that value. C-FILL-IBU can agree, C-COMP sees the correct completeness, and the central-only C-FIX comparison still passes. The affected difference vector is scaled, changing the covariance and empirical bars. `r3:93–94,247–252,270–277,287–295`, `ref_c2c1.py:422–435`, `re2_driver_at_M.py:1316–1335,2479–2481`. **Fix:** validate the fixed normalization arguments actually consumed by extraction in every unit against the checked CV inputs, including the flux vector, POT, nucleons and axes.
