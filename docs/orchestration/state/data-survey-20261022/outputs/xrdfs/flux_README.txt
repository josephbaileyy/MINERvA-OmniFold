This file location holds the parameter and reweight files used by MINERvA Analyses. Updates to the files will result in dated tarballs being placed here, often replacing the previous. These may be available by way of mounting `cvmfs`, but tests of that approach have been inconsistent on non-FNAL machines. For further questions, please reach out to MINERvA Spokespeople. Their contact information are available at minerva.fnal.gov
