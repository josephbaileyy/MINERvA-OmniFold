## 3. Checks by question (condensed)

- **C1 vs code.** Per-event weights are float64 `w × pot_scale` (`unfold_nd…:338,438,567`; `np.asarray` of Python floats). The per-row filters carry no cross-row state, so concatenation, bitwise and ×(s_X/s_ALL) predicates hold on a correct run. Histogram rule: weights are non-negative (`0 <= w`), so no cancellation and 1e-9 is loose (error about 1e-13); empty bins exact. `measured_weights` recomputation uses the same function (`:581-602`), so it passes trivially and affects nothing (not read). `bkg_nd` is likewise unread by config R. Not vacuous for the unread keys only in that it checks the files. Gaps: M4, M5; w = 0 events need an exact-equality rule.
- **K2′.** Decidable; deterministic if 32 threads and the pinned code. m9.
- **N0 validity.** Unfold inputs are valid for `s5p_numerics` if the bkg dump meta, shas and `denom_nd` are fixed (M3). MC weights unchanged with `data_pot` × e is self-consistent (Σ MC weight ∝ e). Power: M2.
- **R1.** Exactly one outcome (enumerated). t̄/σ_d is not used; the gate is t̄/σ(t̄), defined but with no stated convention (m2). Classes computed only under SEES and t̄ gate (N0's t is computed regardless: m4).
- **R2.** Outcome order gives exactly one outcome (INCONCLUSIVE clause 3 is the complement). Circularity: the plug-ins and μ come from the tested data (disclosed); the rank-2 S1 ceiling (M1) is the real remaining defect. Σ_δ divisor (1−V2) verified: E[Σ e g gᵀ] = (1−V2)Σ_δ.
- **Stage 0.** Partition of SEES/ABSENT/OTHER is exact (SEES needs ratio ≥ 5, ABSENT < 3). σ₀ convention matches `fd_ct_periods.py:344-349`. L, H are unions of fine bins (`FINE["pz"]` edges 8, 15). `unreported_boxes` = 4 ✓. m5, m6.
- **§6 wording.** M6, M7, m1. §6.2 (i) is honest (re-opens the block, says it is Joseph's, no recommendation).
- **Constraints.** No CFS read in any job ✓. O_NOATIME via staging: complete except m11 and the default-path hazard M5. No covariance or paper change ✓ (§0, §11). HPSS deferral: m7 (record does not name RPD; margin 12-15 vs 11-06 is fine). CPU only, QOS regular, jobs 1 h and 2 h ✓.
- **Missing before binding:** M1 reachability result; M2/M3 N0 repair; M4/M5 C1 operands; M8 OC decision rule; m12 listing.
