## For the audit

1. **Detached on a login node.** #848's wrapper submits no job (its own header says so), so the connect runs on a login
   node, as the prologues and the class check did. That wrapper stages the 24 dumps, unlike those data-free runs, and
   it can outlast an ssh session, so the runner is detached. The alternative is a foreground run that ends if the
   session drops.
2. **No private record.** If the wrapper stops before `prepare` writes the private record, the fetch still sends the log
   and the run's records, after the `fingerprints` scan only. Prologue 5 sent nothing in that case.
3. **`20261111` as a label.** The run directory keeps that name on any day.
4. **Two fences.** The connect's inline fence and the launcher's `cov2d_fence.sh` refuse `cov2d*` and `t2a*` only.
   Custody's own fence refuses `cov2d-*` and requires its two named jobs to be terminal. LL5D jobs, such as
   `ll5d_gate_*`, pass all three. RPD-RECO reads none of their inputs: those paths are protected (proposal item 4).

Nothing is submitted, deposited or tagged.
