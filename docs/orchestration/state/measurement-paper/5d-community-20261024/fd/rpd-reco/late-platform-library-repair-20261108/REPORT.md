Prepare now resolves the closed thirteen-name inventory under the declared ovis_ldms root, alongside already mapped platform code. Missing files, a symlink escaping the reviewed root, or overlap with a protected input refuse before any ordinary digest read. It pins canonical path, SHA-256, device/inode, size and mtime. These names are source/trace declarations, not a glob that absorbs an additional library. New unpinned libraries on a different node refuse.

The complete inventory is distinct from `platform_mapped`, the instantaneous prepare subset. The worker compares its current mapped subset with that subset and verifies every inventory pin, including libraries not mapped yet. Thus a nonempty exit-hook inventory with an empty mapped subset is valid. Removing a library from the inventory cannot be concealed by both snapshots being empty.
