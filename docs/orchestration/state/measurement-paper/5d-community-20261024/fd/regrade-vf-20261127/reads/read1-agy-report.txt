1. [BLOCKING] regrade_vf.py:128-129 — check_psd (C-PSD) silently passes negative-definite and negative-semidefinite matrices.
   Line 128 computes `lmin_rel = float(lam.min() / lam.max()) if lam.max() > 0 else 0.0`. Whenever `lam.max() <= 0` and `lam.min() < 0`, `lmin_rel` is set to `0.0`, so `lmin_rel < -PSD_REL` is False and C-PSD passes without raising Stop. (Unlike regrade_crep.py:165, which checks `lam[0] < -PSD_TOL * lam[-1]`.)
   Concrete failure scenario: `check_psd(-np.eye(16), "neg")` or `check_psd(np.diag([0.0] + [-1.0] * 15), "neg_semi")` returns `{"asym_rel": 0.0, "lam_min_rel": 0.0}`. A negative-definite `dF_rule_i` (e.g., negative-definite `DeltaC_e`) or `dF_rule_ii` (e.g., `phi_R < 1` in all bands) passes C-PSD silently.

2. [BLOCKING] regrade_vf.py:125-129 — check_psd (C-PSD) silently passes NaN and Inf inputs and crashes on empty matrices.
