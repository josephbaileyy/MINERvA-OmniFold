NumPy 2.4.4 therefore keeps `check_valid='warn'` and absolute `tol=1e-8`: an eigenvalue `< −1e-8` emits `RuntimeWarning`, and only if that call returns does the factor use `sqrt(abs(λ))`. Every rebuilt null runs under `warnings.simplefilter("error")`, so that warning raises before the factor is built, and the declaration names the warning a STOP (`:173`; any failure stops, `:166`). A matrix in the old gap (`λ_max > 10^4` and `−1e-12 λ_max < λ_min < −1e-8`) raises and does not return a flipped-sign sample. At the stated scale `~1e-78`, NumPy's floor `−1e-8` is the looser of the two, so the clause that calls it never the looser one (`:173`) is false; C-PSD's `−1e-12 · λ_max` is the tighter floor there. That gloss is not a second way for the flipped sample to pass.
