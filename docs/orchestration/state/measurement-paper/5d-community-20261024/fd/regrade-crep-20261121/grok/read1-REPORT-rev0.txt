# Regrade declaration review (read-only)

Reviewed `inputs/REGRADE-DECLARATION.md` against `inputs/SCOPING.md`, `inputs/READING-T2-20261110.md`, `inputs/COV2D-DECLARATION.md`, and the code in `inputs/`. Nothing was run. Callee bodies not in this bundle (`fs.load_s1`, `sa.fine_map`, `mc.cmodel_parts`, `sa.flux_weights`, `fs.surrogate`) were not inspected.

## BLOCKING

1. **The 3-SE rule reads the wrong number.** The exact identity (see OK-CHECKS) says that, conditional on the stored errors `e`, a full test that also draws `r ~ N(0, C_add)` independent of `e` has expected mean χ²/ndf equal to `M′ + tr(A C_add) / ndf′`, where `A` is the quadratic-form matrix inside `chi2_nonnull`. `M′` lower-bounds that expectation when `tr(A C_add) ≥ 0`. The reading then compares `M′` itself to 1 (`REGRADE-DECLARATION.md:72-83`).

   Under the same model, correct calibration of `e + r` against `C′` gives `E[χ²(e+r)] = ndf′` on this cut, so `E[M′] = 1 − tr(A C_add) / ndf′`. `M′ < 1` is what the model predicts whenever `C_add` is a real positive share of `C′`. The branch "over-describes on average" if `M′ − 1 < −3 SE` (`REGRADE-DECLARATION.md:83`) treats that predicted deficit as evidence the full covariance is too big. The symmetric "not shown" window (`:82`) has the same center. Both can hide a full-test mean above 1: `M′` sits near or below 1 while `M′ + tr(A C_add) / ndf′` does not.

   That gap is material on the sixteen cells. T2B already shows `C_resp` is large there (`SCOPING.md:46-47`; `READING-T2-20261110.md:19-20`). Scoping fixed the regrade as one-sided: a fail means the fuller covariance still fails; a pass means "not contradicted" (`SCOPING.md:50-53`, `:61-64`). The declaration cites that one-sidedness for the coverage fraction (`REGRADE-DECLARATION.md:95-96`) and then installs a two-sided rule on the statistic wording may rest on (`:72`, `:80-84`). The under-describe branch (`:81`) is the one that follows from the identity: `M′ − 1 > 3 SE(M′)` forces the conditional expected full mean even higher. The other two branches do not.

   The SE itself is a defined sample SE (OK-CHECKS). The defect is the estimand it is applied to. The pre-registered comparison that matches the exact statement is `(M′ + tr(A C_add) / ndf′) − 1` against `3 SE(M′)`, with only the upper tail licensed to carry wording. `SE(M′ + tr/ndf′) = SE(M′)` because the trace is fixed given `C′` and `C_add`.

## MAJOR

1. **`C′⁺` in the trace and the split is not the cut used for χ².** `M′` is defined on `C′`'s non-null subspace (`REGRADE-DECLARATION.md:70-76`). The code keeps eigenvalues above `1e-12` times the largest and inverts only those (`fd_1b_null.py:52`, `:92-97`). `tr(A C_add)` equals the conditional increase of that χ² only for this `A = V_k Λ_k^{-1} V_k^T`. A Moore-Penrose inverse, or `pinv` at another `rcond`, keeps a different set, and the printed trace then does not satisfy the identity the declaration calls exact (`REGRADE-DECLARATION.md:77-79`). The declaration never says the trace, the mean-error term, and the spread term must call the same factorisation as `fd_1b_null.chi2_nonnull`. Bind all three to that function.

2. **A0, as specified, can stop on a faithful rerun.** With `C_add = 0` the toy χ², `ndf`, and `joint_count` are functions of `E` and `C_T` only: `joint_count` uses `chi2_cut = chi2_ppf(P0, ndf)` (`fd_1b_null.py:113-115`; grade excerpt source `fd_1b_mc.py:680`). `k_joint` and the cell flags are not. `grade` rebuilds thresholds from the null's Monte Carlo contents (grade excerpt `fd_1b_mc.py:664`, `:681-682`; `fd_1b_null.py:145-153`). The driver re-simulates `N_MC = 2_000_000` at `cov2d.NULL_SEED` (`cov2d_null.py:50-57`, `cov2d.py:48`, `fd_1b_null.py:47`, `:109-123`). `k_joint` and the flags equal the committed grade only if that redraw reproduces the committed null. A numpy/BLAS change, or a non-bitwise rebuild of `gauss`, moves `p_cell` / `q_joint` and can move an integer flag without the inputs being the wrong files. The `1e-12` relative tolerance on `chi2_mean_over_ndf` (`REGRADE-DECLARATION.md:136`) is also tighter than the conditioning of this χ²: the mean is dominated by the small eigenvalues (`READING-T2-20261110.md:34-35`), and T2A already records eigenvector differences of order `1e-6` between solvers (`:38`). Same-process `C_T + 0` is bitwise; comparison to the historical json is not guaranteed at `1e-12`.

   Two field mismatches make a sixteen-cell A0 fail even when the numbers match:
   - `fd_1b_mc.grade` returns `cell_flag`, not `flagged_cells` (grade excerpt `fd_1b_mc.py:688-693`). `ll5d_b.readout` stores that dict as `grade` (`ll5d_b.py:634`). Only `cov2d_score.score` adds `flagged_cells`, as flat indices (`cov2d_score.py:88`). A0 demands `flagged_cells` against `readout-<t>.json` (`REGRADE-DECLARATION.md:136`). That key is not in the sixteen-cell record. The comparable list is `grade["cell_flag"]` in R00–R15 order.
   - The Cholesky cross-check runs only when `ndf == C.shape[0]`, at `chol_tol` default `1e-9` (grade excerpt `fd_1b_mc.py:657`, `:668-677`). AR23 is declared `ndf = 204` (`REGRADE-DECLARATION.md:62-63`), so the check is off there. The sixteen-cell readout always passes A5's `max(1e-9, 10 κ₂ ε)` and refuses the grade when the comparison exceeds it (`ll5d_b.py:526-532`, `:551-561`; scoping's 3.0–3.7 is "on 16 cells", `SCOPING.md:46`). A driver that calls `grade` at the default `1e-9` raises on a matrix the committed readout accepted, and A0 never reaches the numeric comparison. G18's `ndf` is not stated; the same trap exists if that committed `ndf` is 205. `cov2d_score.score` forwards `chol_tol` (`cov2d_score.py:71-83`) and the original campaign's driver was required to pass A5 (`cov2d_score.py:3-5`).

3. **The sentence wording may rest on names a matrix this study does not grade.** The fail sentence is "the full reported covariance under-describes the toys' errors on average" (`REGRADE-DECLARATION.md:72`, `:81`). Scoping's reported matrices are `Q_R` at the data for 2D and `C_rep = C_total + C_resp + C_PL,5D` for sixteen cells (`SCOPING.md:34-35`). The regrade matrix is `C_T(T) + C_add(T)` (`REGRADE-DECLARATION.md:10-12`, `:70`), i.e. the tune-remade covariance, including `C_model_abs`, plus a fractional carry. COV2D already records that a result at `T` does not carry over to `Q_R` at the data (`COV2D-DECLARATION.md:226-227`). A high `M′` is a statement about `C′` at the tune. It is not, by itself, a statement about the published matrix.

4. **The 2D substitution is valid on the primary null and silently wrong on the leave-out-MEC null inside the same function.** `null_at_T` sets `gauss = C_stat + C_norm + C08 + C_model_abs` and checks it against `blocks["C_T"]` (`cov2d_null.py:52-56`; `fd_1b_null.py:83-89`). Replacing the `C08` entry by `C08 + C_run(T)` and the `C_T` entry by `C_T + C_run(T)` (`REGRADE-DECLARATION.md:91-92`) adds the same matrix to both sides. Absolute `check_matched` residual is unchanged, so C-NULL passes, and `C_run` sits in the Gaussian, which is the declared `r ~ N(0, C_add)` model (`:77-78`). The laws are untouched (`cov2d_null.py:33-46`). That part is valid.

   If the blocks dict also contains `C_T_minus`, the same call rebuilds the MEC variant (`cov2d_null.py:61-65`). After the substitution, `C_T` and `C08` both already include `C_run`, so `minus_abs = C_T_minus − (C_T − C_model_abs)` subtracts `C_run` once and `g_minus` adds it back through `C08`. They cancel. `null_contents` is then called on the original `C_T_minus`, with no `C_run`. `check_matched` still passes. C-NULL (`REGRADE-DECLARATION.md:137`) does not see the omission. The declared R-grade does not say it reads `null_minus`, but it tells the driver to call this function. Drop `C_T_minus` before the call, or add `C_run` to it and to its Gaussian on purpose. The sixteen-cell formula does not have this bug: one `null_contents(laws, gauss + C_add, C_T + C_add, seed=ll5d.NULL_SEED[e])` (`REGRADE-DECLARATION.md:93`) matches `remade`'s split, where laterals stay in the discrete laws and `gauss = stat + normalization + C_model_abs` (`ll5d_b.py:435-456`, `:512-513`).

## MINOR

1. **`S` in the T2A split has no divisor.** `ēᵀ A ē + tr(A S)` equals `mean_t χ²_t` when `S = (1/n) Σ (e_t − ē)(e_t − ē)ᵀ`. `np.cov` defaults to `ddof=1` (as `cov2d_blocks.py:140` and `ll5d_b.py:442` do for `C_stat`), and `n/(n−1) = 300/299` would make the parts miss `M′`. T2A's published parts add to the mean (`READING-T2-20261110.md:30-32`: 13.61 + 2.94 = 16.55; 20.97 + 3.21 = 24.18 against 24.17). "As in T2A" (`REGRADE-DECLARATION.md:75`) has to mean that divisor. Pin it in the driver test.

2. **C-PSD is undefined on A0's zero matrix.** The control divides by `max |C_add|` (`REGRADE-DECLARATION.md:135`, "1e-12 relative"). For `C_add = 0` that denominator is 0. A0 is specified as `C_add = 0` (`:136`) and any control failure stops the run (`:129`). Skip C-PSD when `C_add` is identically 0, or A0 stops before the grade comparison. Separately, `simulate` calls `multivariate_normal(..., method="eigh")` with no `tol` (`fd_1b_null.py:103`). NumPy's default PSD tolerance on that call is absolute `1e-8`. C-PSD allows a negative eigenvalue down to `−1e-12` times the largest (`REGRADE-DECLARATION.md:135`). If that product is below `−1e-8`, the rebuilt null raises on a matrix C-PSD accepted.

3. **The fractional-carry justification names the run-period blocks and not `C_resp`.** The formulas match the code (OK-CHECKS). The "why" paragraph argues double ratios for `C_PL` and `C_PL,5D` only (`REGRADE-DECLARATION.md:49-53`). `C_resp(T) = diag(X_T / f) C_resp diag(X_T / f)` (`:47`) is the C08/lateral pattern, not that argument. There is also no C-MAP-style bitwise check that `cpl_block`'s `f` equals `s1["f"]`, which is the base `remade` uses for laterals (`ll5d_b.py:443`). The 2D side does check `Q["x"] == blocks["x_R"]` (`REGRADE-DECLARATION.md:59-61`). The internal identity `C_PL,5D = diag(f) P_rel diag(f)` (`:52-53`) is a past measurement, not a control in §6.

4. **The cut can drop modes when `C_add` lifts `λ_max`.** `keep` is `λ > 1e-12 λ_max(C′)` (`fd_1b_null.py:95`). A large `C_resp` raises `λ_max` and can push a previously kept `C_T` mode under the new cut. Its mean error then leaves both `M′` and the trace. The identity still holds for the new `A`. Nothing in §6 prints the kept-set difference against `C_T`, or the gap between the smallest kept and largest dropped eigenvalue. That margin is the difference between a stable `ndf` and a χ² jump.

5. **§8 says the capture reads `cpl_block.npz`.** "the capture reads the committed `cpl_block.npz` for those blocks" (`REGRADE-DECLARATION.md:156-157`). `setup` / `remade` / `toy_errors` do not open it, and §5 correctly omits it (`:109-117`). The local driver reads it (`:35`). The exposure sentence is otherwise right: those pscratch dates do not bind the login capture.

6. **`toy_errors` refuses a directory that contains anything else matching the toy glob.** It requires the glob `ll5d_{truth}_toy_{reading}_*.npz` to be exactly the 300 declared names, and it refuses `partial-*` (`ll5d_b.py:597-603`). The §5 list is the right set, and an extra toy file beside it stops the capture. State that the directory view must be exactly those names.

7. **R-grade reuses the committed verdict tokens.** The descriptive grade "giving … COVERS or UNDER-COVERS" (`REGRADE-DECLARATION.md:94`) is the string `grade` returns (grade excerpt `fd_1b_mc.py:693`). The declaration says this grade is read by nothing that reaches wording (`:89`, `:95-96`). The tokens are the same ones T2A says still stand as the existing verdict (`READING-T2-20261110.md:48`). A receipt that prints `UNDER-COVERS` without the "reading, not a proof" line attached will be quoted as a second verdict.

## OK-CHECKS

1. **`E[χ²(e+r)] = E[χ²(e)] + tr(A C_add)` holds on the cut subspace.** `chi2_nonnull` is the quadratic form `y ↦ yᵀ A y` with `A = V_k Λ_k^{-1} V_kᵀ`, `k = {i : λ_i(C′) > 1e-12 λ_max}` (`fd_1b_null.py:92-97`). `A` is symmetric and fixed once `C′` is fixed. For `r` independent of `e`, `E[r] = 0`, `Cov(r) = C_add`,
   `(e+r)ᵀ A (e+r)` expands to `eᵀ A e + 2 eᵀ A r + rᵀ A r`, the cross term has conditional expectation 0, and `E[rᵀ A r] = tr(A C_add)`. Gaussianity is not required for this step; `r ~ N(0, C_add)` (`REGRADE-DECLARATION.md:77-78`) is sufficient. Both sides use `C′`, so the cut's dependence on `C_add` does not break the equality. Mass of `C_add` in the dropped subspace is annihilated by `A` on both sides. `tr(A C′) = ndf′` exactly, including when some positive eigenvalues were dropped. Dividing by the common `ndf′` keeps the equality. Given the stored toys, `M′ + tr(A C_add) / ndf′` is the conditional expected full-test mean, and it is ≥ `M′` when `C_add` is PSD. `M′` bounds that conditional expectation, not one draw of `r`, and not the coverage fraction. The declaration's quantifier "would be `E[M′] + tr/ndf′`" (`:78-79`) matches the unconditional form of the same identity. The assumptions to print (`:85-87`, scoping item a3 at `SCOPING.md:68-72`) match the hypotheses the identity actually uses. No p-value is stated (`REGRADE-DECLARATION.md:19`; `READING-T2-20261110.md:50`).

2. **The SE of `M′` from 300 toys is well defined.** `grade` already computes `chi2.std(ddof=1) / sqrt(n) / ndf` (grade excerpt `fd_1b_mc.py:689-690`), which is `SE(mean χ² / ndf)`. `n = 300` (`REGRADE-DECLARATION.md:29-31`, `:74`; `cov2d.py:46`; `ll5d_b.py:72`). `n ≥ 2`, so the sample sd exists. The toys are separate seeds, so this is the SE of this ensemble's mean given the blocks. It does not include the shared realization `d̃_T`. At `ndf` 204 or 16 the mean of 300 χ²/ndf values is close to normal (skewness of a χ² mean falls as `1/sqrt(n)`), so a 3-SE scale is a stable descriptive cut. It is not a tail probability, and the declaration does not convert it to one. The 3-SE rule is unsound only in the estimand (BLOCKING), not in the existence of the SE.

3. **Fractional carry matches how carried blocks are built. Absolute should stay the sensitivity.** 2D `C_run(T) = diag(x_T / x_R) C_PL diag(x_T / x_R)` (`REGRADE-DECLARATION.md:46`) is the C08 rule in code, `r = x_T / x_R`, `C08 = r[:, None] * C08_R * r[None, :]` (`cov2d_blocks.py:141-142`; docstring `:12-13`, the lines the declaration cites). The pinned file is the same path and sha as `C08_R_FILE` (`cov2d_blocks.py:51-52`; `REGRADE-DECLARATION.md:33-38`), different key (`C_PL` versus `c08`). Sixteen-cell `C_PL,5D(T) = diag(X_T) P_rel diag(X_T)` (`:47`) is the same transport as `C_model_abs = diag(x_T) C_model diag(x_T)` (`cov2d_blocks.py:143`) once `C_PL,5D = diag(f) P_rel diag(f)`. `C_resp(T) = diag(X_T / f) C_resp diag(X_T / f)` is the same transport as the lateral carry `g = X_T / s1["f"]`, `lat = outer(v ∘ g, v ∘ g)` (`ll5d_b.py:443-450`). An absolute (as-is) primary would freeze the data's central value inside a block the code always rescales, including blocks built as `diag(x) * relative * diag(x)`. Printing the absolute carry and not reading it (`REGRADE-DECLARATION.md:55`) is the right place for that alternative. The missing `C_resp` sentence and the missing `f` check are MINOR, not a reason to flip the primary.

4. **Primary null rebuild preserves `check_matched`.** 2D primary path: MAJOR item 4, first paragraph. Sixteen cells: adding `C_add` only to `gauss` and to `C_T` leaves each discrete law's covariance on its own block (`ll5d_b.py:435-451`, `:456`). `check_matched` sums `law.cov() + gauss` (`fd_1b_null.py:83-89`). The residual is unchanged in absolute value. Seed `ll5d.NULL_SEED[e]` is the seed `null_step` already passes (`ll5d_b.py:507-513`). `C_add` is not also entered as a `Discrete` law, so it is not double-counted.

5. **Weakened labels, the outlier cell, and `ndf` 204 do not by themselves move A0's listed numbers.** `weakened_pass` is an extra list; it does not edit `cell_flag`, counts, or χ² (`cov2d_score.py:84-88`). Row order of `E` does not affect `mean χ²`, `joint_count`, or per-cell counts. The seeds (`cov2d.py:46`, matching `:29-31`) are not an A0 input.
