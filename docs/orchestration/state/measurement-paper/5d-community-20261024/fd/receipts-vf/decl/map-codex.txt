## C. Bit-for-bit reproducibility limits

- **Intrinsic timestamp.** `ref_g1_read.py read` writes `written_utc = time.strftime(...)` into the pinned JSON. A fresh unmodified invocation writes a different timestamp even with identical scientific inputs. The bars generator has recorded seeds `20261104` and `20261105`. `ND/ref_g1/ref_g1_read.py:305–310,361–366`; `ND/ref_g1/config.json:80–81`.
- **Exact historical execution argv not found.** `e2sens` has the script, output, host and environment but the ephemeral script’s executed command was not found. `eav` has a usage line and a report tying the local arithmetic to the output. `t2b` identifies run 2’s interpreter, code, inputs and result, but its exact expanded call was not found. The residual and run-period figures have local recipes with the path evidence above; the headline has a recorded argument vector with `<wt>` placeholders. The supplemental writer has a reproducible write branch and explicit output digests; the build records the check commands, while a historical write receipt was not found. These are execution-history gaps. They do not establish nondeterministic arithmetic. `FD/FD-GENCMP-AMENDMENT-E-ADDENDUM-E2-REPORT.md:169–176`; `EAV/step0_metric.py:6`; `T2B/README.md:66–73,86–101`; `GENFIG/README.md:21–22`; `FIGPASS/README.md:138–143`; `REDRAW/runs/round4/f16/CHECKS.txt:1–10`; `NOTE/make_supplemental.py:200–208`.
