**Findings** (also submitted through ReportFindings):

1. **MAJOR: `figures_check` will exit rc 1 on the first E arm, and no test would catch it.**
   - `run_e` passes `pins={}` for `fd_g_figures_check` (`fd_vf_addition.py:569-571`). `Chain.run` only runs the script directly when `pins is None` (`:472-478`).
   - `{}` is not None, so the step goes through BOOT, which calls `T.build_args` and `T.run` (`:458`). `fd_g_figures_check.py` defines only `main()` (`:297`) and imports neither.
   - `fd_gencmp_e.Chain.run` special-cases this tool (`fd_gencmp_e.py:284-287`). The vf copy dropped that special case.
   - The chain stops with control C after the first E arm's figures, before any V_F step. No wrong number is produced, but Phase 1 cannot complete.
   - Fix: in `Chain.run`, run the script directly when `tool == "fd_g_figures_check"`, or pass `pins=None` from `run_e`. Add a test that inspects the real command.

2. **MAJOR: control T's "each side names its matrix" is not implemented.**
   - `curated()` (`:323-347`) checks only the order of truth names and prediction names. It records the `matrix` and `grade_matrix` strings but never asserts them.
   - `fd_cpl_addition.cmd_table` does assert them (`fd_cpl_addition.py:562-566`).
   - The OLD table pins are `sha256` values computed at runtime (`:732`). The only check against the declared constants is the earlier loop at `:641-642`.
   - Fix: assert the OLD and V_F matrix strings per Stage G pair and the `grade_matrix` per F readout.

3. **MAJOR (test gap): the Order tests never reach the OLD product and deposit controls or any V_F arm.**
   - The fake deploy has no `with-cpl/data-product` directory, so `cmd_chain` dies at the "R data_product" check (`:667-669`) in every run. The "no `vf-` call" assertion is therefore vacuous after that point.
   - Nothing tests OLD data-product R, OLD deposit R, `check_r_figures` (patched out at `test:553`), or the V_F section (`:687-732`).
   - Fix: copy those directories into the fake deploy, add failing labels for the product and deposit R checks, and add a happy-path test that reaches the table.
