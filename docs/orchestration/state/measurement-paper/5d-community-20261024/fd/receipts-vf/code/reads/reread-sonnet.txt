## 2–3. New defects

I found no BLOCKER or MAJOR. All of the following are MINOR. None can produce a wrong number or let a failed control pass.

1. **Table-hash check is stricter than the declaration** (`:889-890`, applied at `:992, 999-1000, 897, 903-904`).
   - Failure scenario: `check_table` requires every OLD and V_F arm's `table_sha256` to equal the committed readout's hash. Declaration §6 R excludes strings. If `np.savez_compressed` bytes differ at NERSC (zlib build), the first OLD control refuses.
   - Impact: (a) no, (b) no. A false refusal is costly given the certificate expires 2026-11-26T03:28Z.
2. **A renderer test skips in the deploy** (`test:820-828`).
   - Failure scenario: `test_the_renderer_must_be_e_a2s` calls `skipTest` when the interpreter is E-A2's, which is the NERSC deploy. Declaration §3 requires "the test modules pass with no skip".
   - Impact: (a) no, (b) no. It is a gate conflict.
3. **T silently skips named lists the V_F readout lacks** (`:396-398`, `if ... key in b`).
   - Failure scenario: an E-family readout without curated rows (g_diag, g_followup, g_sens2, flux_boot) that loses a `predictions` list passes T.
   - Impact: (b) no. Those readouts pair no numbers in the table, and the producers' own controls apply.
4. **The Order test's V_F check is keyed on the `vf-` prefix** (`test:1041`).
   - Failure scenario: the V_F block rebuild runs with arm `"vf"` (`:967`) before the OLD controls. That is harmless, since it writes a pinned, byte-checked file. But the "no V_F call before the OLD controls" assertion would not see it.
   - Impact: (a) no, (b) no.
5. **OLD pins in `cmd_table` are circular** (`:517-518`).
   - Failure scenario: `pins` and `pairs` both come from the chain, unlike `fd_cpl_addition.cmd_table`, which checks `COMMITTED`. The earlier loop (`:983-984`) and `A.pinned` re-hash cover it.
   - Impact: (a) no, (b) no.
6. **`R_EXCLUDE` adds `/code` and `/versions` for the E-with string compare** (`:582`).
   - Failure scenario: `fd_gencmp_e.R0_EXCLUDE` excludes only `/argv`, `/code_sha256` and `/extra_block/file`, so a version-string difference would be invisible here.
   - Impact: (a) no, (b) no. The renderer pin covers the environment.
7. **The product's cells CSV carries `rel_sigma_DeltaC_e`** (`:189, 253`).
   - A2 says the readings' per-cell σ table has "no ΔC_e column". This may apply only to the readings table.
   - Impact: spec ambiguity only.
8. **K4 and K5 have no failing test or mutant** (`:236-245`).
   - They are redundant with V3 and K2.
