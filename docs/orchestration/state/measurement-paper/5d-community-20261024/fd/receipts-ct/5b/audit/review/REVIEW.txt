Fitting 2 parameters on 16 cells gives 14 dof, so the code is statistically right. But it changes §3.3, which amendment 1 must name as an error (declaration line 21). It has no stop role.

## LOW

**L1. 5A's noise uses double ratios** (`:399-400`). §5.3(3b) defines d = x_b/x_s42 − 1. The code uses (x/t)_b/(x/t)_s42 − 1, which is playlist_term.py:201-205's form, the one control A3 must reproduce. The two are equal only if 2D's bootstrap leaves t unchanged. Name it.

**L2. OV_pattern for the normalization group is rounding noise** (`:460-463`). The pattern modes are orthogonal to the uniform vector, so b is about 1e-20 and OV about 1e-17. If the normalization block were exactly uniform in relative units, b would be 6e-36 and the guard would refuse (exit 3), as it does on a planted exactly-uniform block. S1's construction `outer(NF f, NF f)/ff` gave 0 hits in 200 random f (`probe_ov_pattern_floor.py`). So this is low risk, but the written values carry no meaning.

**L3. A1's 1e-12 rtol on the floor and g_sig has thin margin** if the 5B readout's numpy/BLAS summed `U @ x` in another order. The relative error reached 3.4e-13 at |D| about 0.3 % (`probe_a1_summation_order.py`). It scales as 1/|D|, so at 5B's smallest g_sig (0.00095) it is about 1e-12. In the same environment the result is bitwise, and the failure mode is a refusal, not a wrong verdict.
