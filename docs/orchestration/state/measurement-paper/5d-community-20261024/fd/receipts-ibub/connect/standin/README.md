# IBUB connect R: the Docker stand-in (2026-11-24)

**By** `director-helper-3`. This follows MSR's stand-in (`docs/orchestration/state/measurability-20261122/connect/standin/`).
The real connect script runs in a Debian container (`Dockerfile.txt`: python:3.11-slim with git and numpy 1.26.4), at
the real paths, with stub `sacct`, `sbatch`, `scontrol` and `git clone`. Nothing contacts NERSC. `standin.sh` is the
driver, and the variant is its argument.

**MEASURES:** the connect's behaviour on each declared path, at fake inputs. **CANNOT AUTHORIZE:** a connect.

## What the stand-in runs

- **The code:** commit `d547fa1fa`, with one change in a local-only stand-in commit, `e060e276`. That commit is never
  pushed and is deleted after the run. `config.json`'s five input pins are set to the sha256 of the stand-in's fake
  bytes; the diff is `standin-commit-config.diff.txt`. Every other byte the connect clones and runs is `d547fa1fa`'s.
- **The connect:** generated by the real `gen_run_connect.py` with M = `e060e276`, sha256 `efcdf1c4…41e`. It
  differs from the real connect only in M and in the six file sums the generator embeds.
- **The inputs:** fake bytes at the real paths: the CV, MC and RooUnfold sources, C-REP's reference, `$K2A`, and the
  600 toy files.
