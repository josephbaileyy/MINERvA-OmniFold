### A. The Batch Job (`ibub_job.sbatch`)
- **Exit 0 contingent on IBUB-DONE:** Lines 193–196 require `publish_done toys 0 "$comp"`. If `publish_done` encounters any failure (existing file, write error, rename error, read-back mismatch), it returns 1 and the job exits 1. Exit 0 is unreachable without a freshly published and verified `IBUB-DONE`.
- **Exit code tracking:** `all_zero` validates array elements for both reference sruns (`r0`, `r1`) and toy lanes (`lrcs`). No pipe status is dropped.
- **`noclobber` side effects:** `set -o noclobber` is invoked at line 113. All subsequent redirects (`lanes-verify.txt`, `$tag.log`, `lane-$1-$2.txt`, `refcheck.log`, `complete.err`, `complete.json`, `IBUB-DONE.tmp.$$`) target paths that are fresh and uniquely named per step or job ID. No legitimate write fails under `noclobber`.

### B. Marker, Barrier, and Provenance Validation
- **Stale/foreign markers:** `marker_ok` requires exact unit identity, matching job ID and deploy HEAD, regular files, matching sha256 digests, and matching embedded NPZ metadata. Stale markers from prior jobs or wrong units cannot pass.
- **Reference srun status:** Waited srun codes are passed directly to `refcheck` via `--step-rc`, requiring `srun_rc == 0`.
- **Barrier integrity:** `barrier_ok` re-hashes both reference products on disk, checks `refcheck.json` provenance, and passes `barrier_sha256` to `complete`. Readout validates `IBUB-DONE` binds `barrier_sha256` to `refcheck.json`'s current digest.

### C. Write Containment
- All writes in `ibub_unit.py` use `write_contained`, checking `inside(cfg, path.parent)` and `os.O_NOFOLLOW`.
- Staged data files verify `inside(cfg, dest.parent)` and copy with exclusive creation `open(dest, "xb")`.
- `ibub_readout.py` enforces `guard_in_root` on `--out`, `TMPDIR`, and `stage` against `/dev/shm/ibub-connect`.
- `ibub_job.sbatch` verifies `StdOut` is a regular non-symlink file under `$RN`.

### D. Non-Finite Handling
- `c_sim_finite` inspects all covered cells across reference and scan extractions, preventing unhandled NaNs from escaping into `C-SIM`.
- `ibu_products` extracts ROOT and NPZ products independently, so non-finite cells are tallied even if companion files fail digest validation.
- `C-K10` reports non-finite discrepancies between ROOT and NPZ rows without double-counting in `C-CELLS`.

### E. Readout Publication and Classification
- Readout builds entirely inside `stage = tempfile.mkdtemp(prefix=..., dir=out.parent)`. Final results are published atomically via `os.rename(stage, out)`.
- A missing truth file triggers `except (OSError, ValueError, KeyError)` and publishes an `INVALID` record.
- A unit with a `FAIL` marker increments `missing` only, emitting `INCOMPLETE` when no other controls fail.

### F. Mutants Runner
- `mutants.py:241` intercepts `_ErrorHolder` and `testsRun == 0`, forcing exit status 2 (`HARNESS`), preventing setup crashes from being classified as kills.

### 3. [MINOR] Low-Level `os.write` in `write_contained` Lacks POSIX Partial Write Handling
- **Location:** [2d-unfolding/ibub/ibub_unit.py:107](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r5/tree/2d-unfolding/ibub/ibub_unit.py#L107)
- **Finding:** `write_contained` performs `os.write(fd, data)` in a single call. Under POSIX / Linux semantics, `write(2)` may write fewer bytes than requested when handling buffers larger than system buffer limits or if interrupted. When writing multi-kilobyte compressed `.npz` arrays ([ibub_unit.py:443](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r5/tree/2d-unfolding/ibub/ibub_unit.py#L443)), partial writes would result in corrupted archives.
- **Concrete Fix:** Wrap `os.write` in a loop to ensure all bytes are transferred:
  ```python
  total = 0
  while total < len(data):
      n = os.write(fd, data[total:])
      if n == 0:
          raise OSError("write zero bytes")
      total += n
  ```
