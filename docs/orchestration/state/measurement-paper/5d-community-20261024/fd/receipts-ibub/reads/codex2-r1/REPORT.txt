## BLOCKING

1. **The batch job does not verify the declared Slurm allocation.** `ibub/jobs/ibub_job.sbatch:2–7,50–55` checks only whether the allocated memory and CPUs can fit four steps. It has no `--time` directive and never compares the effective time limit, QOS, or node count against the declared `11:29:00`, `regular`, and one exclusive CPU node (`IBUB-DECLARATION.md:318–327`). The job tests bypass that production branch (`ibub/test_ibub_job.py:118–122`). **Fix:** Set the declared limit, check one successful `scontrol` response for the effective allocation before launching any step, and test refusals for each mismatch and for a failed query.

2. **`pipefail` is enabled, but failures in the checks that determine job success are discarded.** At `ibub/jobs/ibub_job.sbatch:35,44–46,75–88,125–130`, a failed `git status` can still produce a zero line count and pass, the lane reader loses the producer’s exit status, and the completion function ignores its counting pipeline’s status. The final cleanliness check also filters `__pycache__` despite the stated zero-line requirement. The script writes a provisional `IBUB-DONE` with `rc: 0` before validating it. **Fix:** Check the status of each gate command, validate the exact expected lane and marker sets, and atomically publish one completion record after all checks.

3. **The re-price gate measures only part of each reference run.** Unit timing begins after startup, code checks, input hashing, reference loading, and driver import. It ends before NPZ compression and output hashing. `refcheck` uses that rounded time for the 271.25-second gate, although the batch step already captures wall time with `/usr/bin/time`. A reference can exceed the declared wall limit and still release the toys. **Fix:** Gate on the full successful reference step’s elapsed wall time and retain that measurement in the barrier receipt. `ibub/ibub_unit.py:272,309–322,389–399,433–442`, `ibub/jobs/ibub_job.sbatch:67–72,98–105`, `IBUB-DECLARATION.md:320–329`.

4. **The reference barrier and readout are incompletely bound to the job and deploy.** A pre-existing `PASS` marker makes a unit return success without checking its provenance. The reference barrier checks file hashes and marker names, but accepts references from an earlier job. For example, a cancelled job can leave both references and no `IBUB-DONE`, and a subsequent job can reuse them. The readout checks the caller-supplied job ID and the runner and config hashes, but does not verify the bound deploy commit or a matching barrier receipt. It also reads the 300 expected marker names without detecting extra PASS markers for the tune. **Fix:** Bind the reference products, barrier receipt, and toy markers to the same job and deploy commit. Verify that binding and the exact per-tune marker set before issuing a reading. `ibub/ibub_unit.py:258–265,309–322,391–405`, `ibub/jobs/ibub_job.sbatch:43–48`, `ibub/ibub_readout.py:198–219,247–249,267–276,367–375`, `IBUB-DECLARATION.md:270–274,318–322`.

5. **The protected-tree write exclusion is unenforced at the unit entry points.** `run` and `refcheck` accept an arbitrary `--out`. `refcheck` uses ordinary reads there and writes `refcheck.json`. The batch wrapper checks `$N` as a string, so a symlinked `units`, `logs`, or staging directory can redirect I/O. On the declared paths I found no CFS write and no executable `squeue` call. **Fix:** Before any I/O, enforce resolved destinations under the bound `$N` for units, staging, and job logs, including the scheduler’s output path. Validate the readout’s temporary root before creating directories. If the readout finishes in `/dev/shm`, make the step-5 package explicitly publish the products under `$N` as declared. `ibub/ibub_unit.py:72–82,183–197,385–424`, `ibub/jobs/ibub_job.sbatch:2–7,36–48,61–72`, `ibub/ibub_readout.py:277–283`, `ibub/ibub_overlap.py:53–55`, `IBUB-DECLARATION.md:345–352`.

6. **A non-finite value can evade a comparison or disappear from the failure record.** `max_rel` can return NaN, and Python’s `max` can discard a later NaN. Separately, a non-finite ROOT row can fail C-FILL, causing the readout to skip the FAIL marker before C-CELLS counts it. **Fix:** Reject non-finite operands before reductions, including in C-ROO. Count non-finite K=5 and K=10 cells in available, digest-verified products even when another control failed, and record C-CELLS as INVALID when it fires. `ibub/ibub_unit.py:212–230,289–296`, `ibub/ibub_readout.py:213–216,250–260,325–336`, `IBUB-DECLARATION.md:244–254,275–277`.

7. **Some refusals produce no tune record, and some STOP records retain readings.** The C-TRUTH mask, seed-order, and label checks raise directly, leaving no INVALID JSON. Conversely, IBUB sets the readings and writes the errors NPZ before `Run.finish` can detect an atime or module-origin STOP. 8. **C-G2R runs after the driver import.** The current argv check prevents `--miss-map` from reaching `driver.main`, but the declaration explicitly requires refusal before the driver is imported. The test checks that `run_driver` is never called, leaving the import order untested. **Fix:** Validate the resolved argv before `rc.load_driver()` and test that the loader is never called for either forbidden spelling. `ibub/ibub_unit.py:148–163,277–283,436–448`, `ibub/test_ibub_unit.py:558–564`, `IBUB-DECLARATION.md:260–261`.
