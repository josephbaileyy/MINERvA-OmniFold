## Numbered Findings

### 1. MAJOR: Corrupted or zero-byte `.done` marker causes unhandled crash (`JSONDecodeError`) instead of recording `INCOMPLETE`
- **Location:** `ibub_readout.py:201-204`, `ibub_readout.py:216-217`
- **Problem:**
  In `ibub_readout.py:201-204`:
  ```python
  try:
      marker = json.loads(cb.read_noatime(units / f"{name}.done")[0])
  except OSError:
      missing.append(s)
      continue
  ```
  If a SLURM task aborts abruptly (e.g., node eviction, wall-time limit, or filesystem flush failure) leaving a $0$-byte or truncated `<name>.done` file, `json.loads` raises `json.decoder.JSONDecodeError`. Because `JSONDecodeError` inherits from `ValueError` (not `OSError`), the exception escapes uncaught, crashing the readout with a traceback rather than treating the unit as missing and setting verdict `"INCOMPLETE"`. Similarly, malformed metadata in `z["meta"]` at line 217 raises an unhandled `JSONDecodeError`.
- **Fix:**
  Catch `(OSError, ValueError, json.JSONDecodeError)` in line 203:
  ```python
  try:
      marker = json.loads(cb.read_noatime(units / f"{name}.done")[0])
  except (OSError, ValueError) as e:
      missing.append(s)
      problems.append(f"{name}: unreadable done-marker ({e})")
      continue
  ```
  and wrap lines 216–221 in a `try...except (ValueError, KeyError, OSError)` block that appends `s` to `missing`.

### 2. MINOR: Done-marker omits explicit seed check declared in C-TRUTH
- **Location:** `IBUB-DECLARATION.md:240-241`, `ibub_unit.py:310`, `ibub_readout.py:201-228`
- **Problem:**
  Declaration §5 states: *"The IBU unit's done-marker and meta name the same seed."* `ibub_unit.py:310` writes `"unit": name` without a `"seed"` key, and `ibub_readout.py:201-228` checks `meta.get("seed") == s` but never validates `marker.get("unit") == name` or `marker.get("seed") == s`.
- **Fix:**
  In `ibub_unit.py:310`, add `"seed": unit["seed"]` and `"tune": unit["tune"]` to the marker payload. In `ibub_readout.py:222`, verify `(marker.get("unit"), marker.get("seed")) == (name, s)`.
