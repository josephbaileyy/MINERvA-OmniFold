### 1. BLOCKER: `g2r_check` in `ibub_unit.py` is hardcoded to a no-op, completely disabling C-G2R
- **Citation**: [ibub_unit.py:144-149](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r1/inputs/ibub_unit.py#L144-L149)
- **Detail**: In [ibub_unit.py:146](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r1/inputs/ibub_unit.py#L146), `bad = []` is hardcoded. It never checks `argv` against `cfg["g2r_forbidden_options"]`. Combined with [ibub_unit.py:269](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r1/inputs/ibub_unit.py#L269) which sets `"pass": True`, control C-G2R is entirely bypassed. Any invocation passing `--miss-map` or other forbidden options will silently pass into the driver.
- **Fix**: Replace line 146 with:
  ```python
  bad = sorted({a.split("=", 1)[0] for a in argv} & set(cfg["g2r_forbidden_options"]))
  ```

### 2. MAJOR: `stage_data` in `ibub_unit.py` leaves orphaned staged files upon copy failure, blocking retries
- **Citation**: [ibub_unit.py:179-189, 305-307](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r1/inputs/ibub_unit.py#L179-L189)
- **Detail**: In `stage_data`, `rc.copy_noatime(src, dest)` opens `dest` with mode `"xb"`. If `copy_noatime` detects a digest mismatch or I/O error ([ref_c2c1.py:102](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r1/inputs/ref_c2c1.py#L102)), it raises `GateFailure` before `stage_data` returns `dest`. Consequently, in `run_unit`, `data_copy` remains `None`, so `run_unit`'s `finally:` block does not unlink `dest`. An incomplete or corrupt `dest` remains in `$N/stage/data/`, and any retry will crash with `FileExistsError`.
- **Fix**: In [ibub_unit.py:185](file:///private/tmp/claude-501/-Users-josephbailey-local-research-MINERvA-OmniFold/a4ec4b9a-c277-4847-8576-4e2ef26708b1/scratchpad/agy-code-r1/inputs/ibub_unit.py#L185), wrap `copy_noatime` in a try/except:
  ```python
  try:
      got = rc.copy_noatime(src, dest)
  except Exception:
      if dest.exists():
          dest.unlink()
      raise
  if got != want:
      dest.unlink()
      raise GateFailure(f"C-DATA: {src} sha256 {got[:12]} != {want[:12]}")
  ```
