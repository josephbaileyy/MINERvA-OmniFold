## 6. Notes on what I did not do

No cluster access; no pscratch file was opened (staged-file contents, flux equalities and unfold sparsity are argued from code and receipts, not measured). The toy simulation in `sim.py` uses an identity metric and Gaussian noise and is evidence about size only.
